## 나중에 할 일 (언젠가 반드시 — 잊지 말 것)

### 📌 분기 만족도 조사 프로세스 (2026-08-09 보류 결정)

**왜 남겨두나** — 승인된 템플릿 `POST_MEETING`이 채널에 살아 있는데, 원래 용도(모임별 후기)는 폐기됐다. 이걸 **분기 만족도 조사**로 재활용하기로 방향만 잡고 이번 범위에서는 뺐다. **삭제하지 않고 보류 상태로 둔 이유가 이것이다.** 정리하다 지우면 안 된다.

**정해야 할 것**
- 설문 도구 — 구글폼 / 자체 페이지 / 외부 서비스
- 발송 주기·대상 — 분기 1회, 최근 3개월 참여자 기준으로 잡았으나 미확정
- 문안 재작성 + 카카오 재심사 (링크가 정해져야 버튼을 단다)

**이미 검토해둔 것** (다시 하지 말 것)
- 모임별 후기 → 분기 조사로 바꾸면 물어보기(모임 다음날)와 **발송 시점이 안 겹친다.** 원래 충돌이 이것 때문이었다
- `/my/reviews` 라우트는 **불필요.** 폼으로 대체 가능
- ⚠️ **응답 대가로 쿠폰·포인트·경품을 걸면 광고성이 되어 심사 반려.** 대가 없이 설계해야 한다
- 문구 초안과 문장별 근거는 대화 기록에 있으나 미확정. 상세: `검토문서/2026-08-07-템플릿-정리-계획.md` §3
