# 지독해 전체 화면 점검 자료 (2026-10-13)

운영 중인 코드(최신 main)를 **가상 데이터**로 띄워 찍었다. 실서비스 DB·미리보기 미사용. 닉네임·실명(김가상 등)·전화(010-0000-)·계좌·사업자 정보 모두 지어낸 값.
폰 390 너비(2배 해상도), 운영자 화면은 대표 상태 1장씩 데스크톱 1280 추가. 긴 화면은 전체 한 장.
「옛 화면」= 새 화면 스위치를 끄면 다시 보이는 구 UI(지금은 새 화면으로 넘어감). 「옛 스킨」= 지금도 옛 머리글로 렌더되는 화면.
비로그인 상태로 회원 화면을 열면 모두 로그인 화면(23번)으로 넘어간다.
