## 5. 건드리지 않은 겹치는 문구 (다른 작업 담당)

| 담당 | 표준과 다른 문구 |
|---|---|
| 홈 「다가오는 정기모임」 작업 — 홈 화면 | 「· 입금 확인 중」(→ 표준은 「입금 확인 전」) |
| 발제 작업 — 발제자 패널·발제자 문구 | 「입금 대기」 4곳, 「돌려줄 금액」 5곳, 결제 수단 「이체」, 「대기 1번 …님이 바로 확정돼요」, 모임 상세·취소 거절 메시지 「참석이 어려우면 운영자에게 알려 주세요」(→ 운영진) |
| 가입 작업 — 가입 환영·프로필 입력 | 「처음 오는 사람이 제일 많습니다」, 「프로필 저장에 실패했습니다」, 「네트워크 오류가 발생했습니다. 다시 시도해주세요.」, 「반갑습니다!」 |

## 6. 알림톡 결제상태 라벨 확인 결과

- 알림톡에 넘기는 「입금 확인 중」/「결제완료」 라벨은 **그대로 뒀다.** 템플릿 본문이 아니라 변수 값이라 재심사 대상이 아닐 가능성이 높지만, 카카오 쪽 기준을 직접 확인하지 못해 확실하지 않다.
- 같은 이유로 0원 모임 「무료」 표기도 그대로 뒀다 — 금액 표기 함수가 알림톡 `#{결제금액}`과 홈 화면에도 쓰인다.

## 7. 판단해서 바꾼 것 (알려 둘 것)

- 운영자 35번 「미입금 취소」 → 「입금 전 취소」. 「미입금」이 금지어라 **글자만** 바꿨다. 0원·입금 전 취소를 가르는 판단은 그대로.
- 정산 환불 대기의 「환불할 금액」(어제 보완 때 넣은 말) → 「환불 예정 금액」, 「낸 돈」 → 「결제 금액」. 금액 계산은 그대로.
- 모임 탭 띠는 「신청 완료」「신청 완료 · 입금 확인 전」「대기 중」을 쓰려고 입금 전인지 여부를 하나 더 읽게 했다(화면 표시용, 저장 값 변화 없음).
- 신청 내역 「환불 완료 · N원」은 대기 취소·대기 종료 건에도 붙는다(전에는 취소 건에만 「환불 N원」).
