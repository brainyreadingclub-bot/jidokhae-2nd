## 시안이 정한 것 (결정 문장 안에서 디자인이 채운 빈칸)

| 정한 것 | 왜 |
|---|---|
| **한 화면에 질문 넷, 순서 = 관심 분야 → 시간 → 알게 된 경로 → 가입 이유** | 「나」에 관한 질문(취향·시간)이 먼저 와야 답하는 재미가 있다. 경로·이유는 운영자 쪽 질문이라 뒤로 |
| **전부 칩 고르기, 자유 입력은 「경로 · 기타」 하나만(20자)** | 경로는 우리가 모르는 새 길을 알려 주는 유일한 질문이라 칸이 필요하다. 이유·분야에 자유 칸을 열면 「의미 없는 응답」(구글폼 문제 셋 중 하나)이 돌아오고 처리방침에 적을 범위도 넓어진다 |
| **시간 = 평일/주말 × 오전/오후/저녁 6칸 표, 여러 개** | 결정 문장의 「×」를 그대로 그렸다. 요일 2개·시간대 3개를 따로 고르게 하면 「평일+주말, 오전+저녁」이 평일 오전인지 주말 저녁인지 알 수 없다. 칸이 6개뿐이라 표가 무겁지 않다 |
| **「저장하기」는 하나라도 골라야 켜진다** | 아무것도 안 고르고 저장 = 건너뛰기와 같은 일인데 버튼이 둘이면 헷갈린다 |
| **건너뛰기·저장 둘 다 홈으로, 토스트 한 줄** | 결정대기 「신규 회원 첫 화면에 할 일 하나」(첫 신청)와 자리를 다투지 않게 — 설문이 끼어든 뒤에도 첫 신청까지 탭 수는 「건너뛰기」 1번만 는다 |
| **설문은 한 번만 보인다** (가정) | 건너뛰거나 저장하면 다시 안 띄운다. 앱을 그냥 닫아 버린 경우도 「한 번 보여 줬다」로 치는 쪽을 권한다 — 다음 방문에 또 뜨면 관문처럼 느껴진다. 구현 방식은 개발·운영이 정한다 |
| **나중에 고치는 곳 = 나 탭 한 줄, 관심 분야·시간만** | 둘은 살다 보면 바뀐다. 알게 된 경로·가입 이유는 가입 때의 사실이라 고칠 일이 없다 — 화면에서 뺐다. 대신 「답 모두 지우기」는 넷을 다 지운다(아래 처리방침 §7과 짝) |
| **화면 맨 아래 고지 한 줄 + 처리방침 링크** | 「선택해서 알려주는 정보 · 안 골라도 신청에 영향 없음 · 나 탭에서 고치거나 지울 수 있음」. 동의 체크칸은 **그리지 않았다** — 필요한지는 아래 「확인 필요」 1번 |
| 문구 어미 = 지금 5탭 화면 말투(해요체) | ⚠️ `VOICE.md`는 카카오톡 메시지 전용이고 인앱 문구 기준은 어느 문서에도 없다(2026-08-26 결정). 기존 5탭 화면 문구 결을 따랐을 뿐 기준 문서를 근거로 쓰지 않았다 |
| 첫 화면 문구 「답은 운영진만 봐요」 | 모임후기 시안과 같은 말. 열린 질문 3이 「admin만」으로 정해져도 회원에게 「총괄운영자」는 낯선 말이라 이대로 둔다 |

- 「다른 모임 앱」은 특정 서비스 이름을 쓰지 않았다. 실제로 많이 오는 앱이 있으면 이름으로 바꾼다.

### 확인 필요 — 디자인이 정할 수 없는 것

1. **선택 항목에 별도 동의 체크칸이 필요한가.** 시안은 체크칸 없이 「고지 한 줄 + 처리방침 링크」만 뒀다. 필요하다고 나오면 「저장하기」 위에 체크칸 하나가 들어가고 01·03·04가 바뀐다. 법 확인이 먼저다.
2. 위 표의 ⚠️ 셋(회원 한 명 단위로 보는 것이 목적에 드는지 · 데이터베이스 지역 · 변경 안내 경로).
3. 기존 회원에게는 묻지 않으므로, 이 개정이 **기존 회원에게 따로 알릴 일인지**(그들은 새 항목을 낼 일이 없다).

## 열린 질문 (대표님께, 셋)

1. **선택지 목록이 맞나요?** 특히 「어떻게 알게 됐어요?」 — 실제로 회원이 들어오는 길은 대표님만 아십니다. 빠진 길·없는 길을 고쳐 주세요. (권고: 경로는 하나만 고르기 + 기타 20자)
2. **나 탭 「관심 분야 · 시간」 줄을 기존 회원에게도 보일까요?** 권고 — **설문을 본 신규 회원에게만.** 「기존 회원에게는 묻지 않는다」는 결정 문장에 가장 가깝다. 다만 기존 회원의 시간대도 모임 시간 정하는 데 쓸모가 있어서, 보이게 하면 묻지 않고도 모일 수는 있다.
3. **응답을 운영진(editor)도 볼 수 있게 할까요?** 권고 — **총괄운영자만**(A1). 2026-04-23 권한표가 editor에게 이름·닉네임·지역까지만 열어 두었고, 설문 답은 그 바깥이다.
