## 흐름에서 시안이 정한 것 (대표님 지시 안에서 디자인이 채운 빈칸)

| 정한 것 | 왜 |
|---|---|
| **한 화면 = 한 질문, 4단계** + 위에 `1 / 4` | 표정만 하고 나가도 되게. ②③④는 전부 「건너뛰기」가 있다 |
| **각 단계 「다음」에서 바로 저장** (가정) | 가장 중요한 표정이 뒤 단계 이탈로 사라지지 않게. 구현 방식은 개발·운영이 정한다 |
| 낮은 점수 = **1·2**(「별로였어요」·「아쉬웠어요」) | 「무난했어요」까지 물으면 대부분이 한 번 더 고르게 돼 무거워진다 |
| 칭찬 대상 = 같은 모임 **참여(확정 + 입금 대기) 중 본인 제외** | 기존 「함께하는 멤버」 명단과 같은 집합. 「못 갔어요」라고 한 사람도 목록에는 남는다(누가 그렇게 답했는지 다른 회원에게 드러나면 안 되므로) |
| 후기 받는 기간 = **모임 다음 날 ~ 3일 뒤**(칭찬 전달 전날까지) | 칭찬을 4일 뒤에 모아 보내려면 그 전에 닫혀야 한다. 지난 뒤는 12번 화면 |
| 공개 소감이 보이는 곳 = **같은 지역 다음 정기모임 소개** 「지난 모임에서 남긴 한 줄」 | 처음 오는 사람이 「어떤 모임인지」 보는 자리가 모임 소개다. 지난 모임 상세에도 같은 묶음이 붙는다고 가정(별도 화면은 그리지 않음 — 같은 조각) |
| 공개는 **내리기·다시 공개 둘 다** 가능(15) | 철회만 되고 다시 못 켜면 「한 번 내리면 끝」이 무서워 처음부터 안 켠다 |
| 운영자 화면에 **칭찬 없음** | 「개수·순위 어디에도 표시하지 않음」 — 운영자 화면도 「어디에도」에 넣었다 |
| 표정 그림 = 인라인 SVG(이모지 아님) | 기기마다 이모지 얼굴이 달라 「아쉬움」의 세기가 달라 보인다 |

## 「무엇이 아쉬웠나요?」 선택지 후보 (여러 개 고름, 운영진만)

1. 이야기할 시간이 짧았어요
2. 몇 사람 이야기가 길었어요
3. 진행이 매끄럽지 않았어요
4. 대화에 끼기 어려웠어요
5. 공간이 불편했어요 *(소음·자리·온도)*
6. 책이 잘 안 맞았어요
7. 시간·장소 안내가 헷갈렸어요
8. 기타 *(짧은 입력칸, 운영진만)*

- 사람을 지목하는 선택지는 두지 않았다(2는 「몇 사람」으로 뭉뚱그림) — 운영진만 봐도 지목형은 답하기 부담스럽다
- 운영자가 **고칠 수 있는 것** 순서로 놓았다: 진행(1~4) → 공간(5) → 책(6) → 안내(7)

## 알림톡 문안 초안 — 새 템플릿 가정

> 🔴 지금 승인된 `BOOK_ASK`(책 담기)는 **건드리지 않는다.** 아래는 새 템플릿으로 제출한다고 가정한 초안이다. 제출은 대표님 승인 뒤(사람이 제출). 혜택·홍보 문구 없음. 이모지 없음. 느낌표는 `똑똑!` 하나.

### 안 A (권장) — 할 일을 짧게 다 말한다

```
[강조 부제]  표정 하나면 충분해요
[강조 타이틀] 모임 어땠어요?

그날이 어땠는지 표정으로 골라 주세요. 표정은 운영진만 보고, 다음 모임을 꾸릴 때 참고해요.

한 줄 소감, 함께한 분께 칭찬, 읽은 책 담기는 하고 싶을 때만 하셔도 돼요.

▪ 모임에 참여하신 분께 모임당 한 번만 보내드려요.
```
버튼: `채널 추가`(AC) · `후기 남기기`(WL)

```
[강조 부제]  표정은 운영진만 봐요
[강조 타이틀] 모임 후기를 받아요
```

**A를 권하는 이유** — 버튼을 누르기 전에 「표정만 하면 되고 나머지는 선택」이 보여야 누른다(VOICE §3-6 다음이 예상되게). B는 짧지만 눌렀을 때 질문이 4단계로 나와 예상과 어긋난다.

- `file://`가 막혀 있어 이 폴더를 `127.0.0.1` 정적 서버로 띄워 찍었다. 다 찍고 서버를 껐다
- 고친 것(자가검토): 360에서 표정 라벨이 붙어 「보통이었어요」→「무난했어요」 · 「칭찬하기」 버튼을 회색으로(그린 면이 여섯 개 쌓여서) · 운영자 낮은 표정 강조를 코럴→굵은 글씨(코럴은 에러·긴급에만) · 「서재 탭에서 지금도 담을 수 있어요」 삭제(서재 탭은 지금 담기 수단이 없다 — DECISIONS 2026-09-19 ⏸) · 정기모임 소감 예시에서 「발제」 단어 삭제 · 운영자 숫자 합(참여·후기·평균)이 서로 맞게 정리
