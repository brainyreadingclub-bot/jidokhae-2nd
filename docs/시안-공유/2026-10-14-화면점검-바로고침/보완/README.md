# 바로 고칠 것 — 보완 확인 사진 (2026-10-14, 가상 데이터)

수정 후 화면을 가상 데이터로 띄워 찍었다. 실명·전화·계좌는 지어낸 값.

- A·B 정산 「환불 대기」 — 「환불할 금액」(규정 기준)을 크게, 「낸 돈」을 작게. 책벌레 건: 모임 2일 전 취소 → 5,000 / 낸 돈 10,000
- C 같은 건의 모임 운영 상세 — 「환불 필요 · 환불 5,000」으로 A와 같은 금액
- D2 회원 신청 내역 — 같은 건에 「환불 진행 중」
- E 계좌이체 단계 — 「입금이 확인되면 신청이 확정돼요」 + 「계좌이체로 신청하기」
- F 0원 모임 — 「신청하기」 그대로
- G 정책 화면에서 오류가 날 때 — 새 공통 오류 화면(전에는 Next 기본 영문 화면)
- H·I 결제 확인 중 — 스위치 켬: 새 머리글 / 스위치 끔: 옛 머리글 그대로
