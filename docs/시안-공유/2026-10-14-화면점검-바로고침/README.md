# 화면 점검 — 바로 고칠 것 5개 (2026-10-14)

가지 `fix/screen-audit-five`의 고치기 전·후. **가상 데이터**(로컬 가짜 서버)로 찍었다. 실서비스 DB·미리보기·결제는 쓰지 않았다.
「전」은 `main`(f9b5fc8), 「후」는 이 가지. 폰 390 너비, 2배 해상도. 닉네임(책벌레·새싹독자)·회원 수·사업자 정보는 모두 지어낸 값이다.

| 번호 | 무엇 | 바뀐 점 |
|---|---|---|
| 01 | 없는 주소 | 영문 기본 화면 → 한국어 안내 + 「홈으로」, 새 화면 머리글 |
| 02 | 없는 모임 주소 | 영문 기본 화면 → 「모임을 찾을 수 없어요」 + 「모임 목록 보기」 |
| 03 | 모임 탭 — 데이터 요청 실패 | 빈 목록(「예정된 정기모임이 아직 없어요」) → 오류 화면 + 「다시 시도」 |
| 04 | 모임 탭 — 진짜 0건 (후만) | 그대로 빈 화면. 03과 구분된다는 것을 보이려고 넣었다 |
| 05 | 이야기 탭 — 요청 실패 | 「다음 토론모임을 준비하고 있어요」 → 오류 화면 |
| 06 | 서재 — 요청 실패 | 「아직 담은 책이 없어요」(0권) → 오류 화면 |
| 08 | 오류 — 옛 화면 쪽 | 「문제가 발생했습니다」 + 개발용 문구 노출 → 새 화면과 같은 모양, 개발용 문구는 콘솔에만 |
| 09 | 오류 — 운영자 화면 쪽 | 08과 같음 |
| 10–15 | 결제 확인 중 | 옛 머리글(「닉네임님 · 로그아웃」)·사업자 정보 푸터 → 새 화면 머리글. 문구 해요체. **11 회원이 취소 / 12 결제 실패를 다른 문구로** |
| 16–17 | 결제 실패 화면 | 위와 같음. 16 취소 / 17 실패(결제사 사유를 작게 붙임) |
| 18–19 | 로그인 | 약관 동의 체크를 카카오 버튼 **위로** 올렸다. 버튼 규격은 그대로 |

새 화면 쪽 오류(모임 상세)는 이미 목표 모양이라 바꾸지 않았고 사진도 뺐다(07번 비움).
