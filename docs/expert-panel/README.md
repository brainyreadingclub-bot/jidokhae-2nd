# 전문가 패널 기록

## 이 폴더는 근거지, 권위가 아니다

여기 있는 것은 **그날 무엇을 논의했는지의 기록**이다. 결론이 아니다.

무엇이 정해졌는지는 **[`검토문서/DECISIONS.md`](../../검토문서/DECISIONS.md)**에 있다. 둘이 다르면 `DECISIONS.md`가 이긴다. 패널 기록은 "왜 그렇게 정했나"를 되짚을 때만 연다.

> ⚠️ **패널 의견을 그대로 따르지 말 것.** 패널은 서비스 맥락을 모른 채 강하게 주장하는 경향이 있었다. 실제로 *일부러* 그렇게 둔 설계를 결함이라고 지적한 전례가 있다. 읽을 때는 "이 지적이 우리 사정을 알고 한 말인가"를 먼저 따진다.

`DECISIONS.md`가 이 폴더의 파일 4개를 직접 링크한다. **그래서 파일명을 바꾸면 결정 기록이 깨진다.** 이름이 들쭉날쭉해도 그대로 두는 이유다.

## 이름 규칙 (앞으로 만드는 것만)

`YYYY-MM-DD-주제.md` — **시각(`-HH-MM`)은 붙이지 않는다.**

기존 파일 5개에 시각이 붙어 있는데(`20-04`, `13-00`, `19-55`, `21-30`, `11-36`) 같은 날 두 번 연 적이 없어 쓸모가 없었다. **이미 있는 것은 고치지 않는다** — 링크가 깨진다.
