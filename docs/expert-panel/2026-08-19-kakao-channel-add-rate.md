# Expert Panel: 카카오 채널 친구 추가율 높이기
> 2026-08-19 | 패널 5명

## 질문
카카오 채널 친구 추가(+ 마케팅 수신 동의) 비율을 높이는 방법 — 250명 규모 지역 독서모임 서비스(지독해). 로그인 동의 화면의 '채널 추가' 체크율이 낮음. ① 신규 가입자 사전 설득 ② 기존 회원 240여 명 유도.

## 라운드 1: 독립 의견 (요지)

### 📈 한퍼널
체크율은 동의 화면 직전·직후에 결정된다. 로그인 버튼 위 한 줄(손실 회피 프레임: "마감 빠른 모임 오픈 소식을 가장 먼저") + 신청 완료 화면에 채널 추가 버튼. "월 몇 회만 보내요" 같은 방어 카피는 역효과. GA4 계측 후 A/B.

### 💬 채널만
동의 화면 체크박스는 원래 낮은 자리 — 채널 홈 URL·QR·단톡방 공유·**알림톡 하단 '채널 추가' 버튼**(템플릿 등록 시 버튼 유형)이 주 경로. **채널 추가 ≠ 마케팅 수신 동의 — 별개 개념이니 뭉뚱그리지 말 것.** "채널 친구만의 실질 혜택"(오픈 선공지 등)이 없으면 추가해도 곧 차단.

### ⚖️ 남정보
현재 구조("채널 없이도 모든 기능 사용 가능") 유지 시 사전 설득은 적법. 금지선 3개 = 이용 흐름과의 **결합**·혜택 과장 등 **기만**·거절자 **반복** 재요청. 문구에는 혜택+빈도+비필수성 3요소. 최대 리스크는 유도가 아니라 발송 단계 — 거래정보성 알림톡에 홍보 문구를 섞는 순간 §50 위반(과태료 최대 3천만원).

### 🫂 모임장
앱 배너 3% vs 단톡방 15% vs **모임 자리 구두 요청 80~90%**. 모임 마무리 5분 "채널 추가 타임"(QR 인쇄물 + "공지 여기로만 가요") 2~3주 캠페인 → 이후 신규 온보딩 루틴에만. 매주 반복하면 잔소리 — 신뢰 자산 소모.

### 🧊 미니멀 (반대)
전송 실패가 실제 사건인가? 지금 최적화하려는 건 **아직 안 쓰는 채널(친구톡)의 도달률**이다. 로그인 화면 설득 문구는 "3초-3클릭" 원칙을 서비스 스스로 어기는 첫 선례이자 '내 독서모임 → 나에게 팔려는 서비스' 프레임 전환 비용. 디지털 장치 전부 보류, 오프라인 한마디면 충분.

## 라운드 2: 토론

### 핵심 논쟁점
1. **로그인 페이지 문구를 넣을 것인가** — 한퍼널(적극) vs 미니멀(반대: 원칙 훼손·프레임 비용) vs 남정보(3요소 갖추면 적법·건전). 모임장·채널만은 "그 자리 효율이 낮다"는 데서 미니멀에 실질 동조.
2. **주력 경로** — 온라인 넛지(한퍼널) vs 오프라인 의식(모임장) vs 알림톡 버튼(채널만). 250명·주간 오프라인 접점이라는 조건에서 오프라인·알림톡의 기대 전환이 압도적이라는 데 이견 없음.
3. **지금 할 일인가** — 미니멀의 "플랜 B를 위한 최적화" 지적에 대해, BOOK_ASK 재심사 계류로 플랜 B 현실화 가능성이 실재한다는 반론(맥락 사실) 성립. 단 "보험 가치"이지 "긴급"은 아니라는 데 수렴.

### 최종 합의
250명 규모에서 채널 친구를 모으는 본선은 화면이 아니라 **모임 자리와 알림톡 버튼**이다. ① 오프라인 "채널 추가 타임"(2~3주 한정 캠페인, QR + 회원 이익 언어 한 문장 + 당일 저녁 단톡방 후속 1건)을 주력으로 하고, ② 다음 알림톡 템플릿 등록 기회에 하단 '채널 추가' 버튼을 포함해 전 회원 도달면을 확보한다. ③ 로그인 페이지 문구는 신규 가입자 한정 보조 수단으로 가치가 있으나, 남정보의 3요소(혜택·빈도·비필수)를 갖추고 "마케팅" 냄새를 빼는 조건이며 — 넣을지 자체는 미니멀의 반대가 남아 운영자 결정 사항. ④ 어떤 경우에도 거래정보성 알림톡에 홍보 문구를 섞지 않는다.

### 액션 아이템
1. (단무지님) 다음 정기모임부터 2~3주 "채널 추가 타임" — A5 QR 인쇄물, 마무리 5분, 당일 저녁 단톡방 링크 1건
2. (Claude) BOOK_ASK 승인 후 다음 템플릿 작업 시 '채널 추가' 버튼 포함 검토 — 솔라피 등록 화면에서 버튼 유형 확인
3. (결정 대기) 로그인 페이지 한 줄 — 채택 시 문구: "다음 화면에서 채널을 추가하면 모임 소식을 받아볼 수 있어요 (선택)"
4. (백로그) 신청 완료 화면 채널 추가 버튼 + GA4 `channel_add_click` 계측

### 미합의 사항
로그인 페이지 문구 삽입 여부 — 미니멀 반대 유지 (화면의 조용함 > 신규 가입자 소폭 전환). 운영자 결정으로 넘김.
