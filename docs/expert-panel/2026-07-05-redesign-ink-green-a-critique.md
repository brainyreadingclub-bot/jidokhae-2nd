# Expert Panel: 지독해 리디자인 A안("모던 잉크 그린") 디자인 평가
> 2026-07-05 | 패널 5명

## 질문
지독해(독서모임 웹서비스, 타겟 2535) 리디자인 유력안 A "모던 잉크 그린"(#127A5A 앵커 + 오프화이트/웜그레이 뉴트럴 + 에디토리얼 세리프 제목 + Pretendard 본문, 앵커색은 CTA/활성날짜/가격 '점'에만)이 정말 2535를 끌어들일 완성도인지, 약점은 뭔지, 로고/브랜드 확장 시 문제는 없는지 평가.

반려 히스토리: 따뜻함/크림(올드), 형광펜/다색(유치), 다크모드(밍밍), 페이퍼+약한포인트(별로), 풀채도 색면(극단). 조사로 "앵커 1색 점 + 절제된 뉴트럴 + 에디토리얼 타이포"가 2026 한국 2535 정석(토스/당근)으로 검증됨.

## 라운드 1: 독립 의견

### 🎨 지현 (브랜드)
**핵심:** 색·타이포 시안으로선 방향이 옳지만, 지금은 "브랜드"가 아니라 "잘 정돈된 UI 테마". 심볼/워드마크 없이는 아이덴티티가 안 선다.
**근거:** 잉크 그린+세리프는 이미 흔한 '지적/차분한 브랜드' 공식(밀리의서재·롱블랙·독서 큐레이션 다수). 앵커색 하나에 의존하면 로고 없이 스크린샷 봤을 때 "이게 지독해다" 식별 근거가 0. 토스/당근이 1색으로 서는 건 강력한 워드마크·심볼(당근이)이 색을 '소유'하기 때문. '지독해'는 이름 자체가 언어유희(지독하게/독해)라 심볼 여지가 큰데 안 쓰면 최대 자산 방치.
**리스크:** 경주/포항 250명 로컬인데 색·타이포만으론 지역·소속감이 안 붙어 확장 시 무색무취.
**추천:** 홈 확정과 동시에 워드마크+심볼(이름 언어유희) 1안 착수 → 잉크 그린을 '소유'시켜 브랜드 자산으로 승격.

### 📐 태오 (UX)
**핵심:** 색은 정해졌지만 홈이 "이번 주"에 갇혀 첫 진입자의 다음 행동을 설계 못 함. 카드 CTA 상태 분기 누락.
**근거:** "이번 주" + 날짜칩(토~화)은 화요일 이후 진입/마감 시 죽은 화면. "3초 안에 신청 가능한 다음 모임" 보장 실패. 카드가 모집중/마감임박 2상태뿐이고 CTA는 "신청하기"로 고정 — 실제론 마감(→대기)·이미신청(완료/입금대기)·종료에서 라벨/동작이 달라야(PRD 버튼 5종). 상태를 칩에만 걸고 CTA에 반영 안 해 최대 전환요소가 위계상 어긋남.
**리스크:** "이번 주" 프레임이 재방문자 본인 신청 인지(MyMeetings)를 밀어내면 첫 화면에서 원칙(모여야·보여야) 깨짐.
**추천:** 카드 CTA를 상태 기반 5종 분기로 명세 + "이번 주 없음/다 마감" 폴백(다음 모집 + 본인 현황) 빈 상태 시안 추가.

### 🔥 민서 (2535 감도 · 반대 관점)
**핵심:** A는 "안 촌스러운 합격선"일 뿐, 2535가 스토리에 올리고 싶은 물건은 아니다.
**근거:** #127A5A+오프화이트+세리프는 2023년 이후 브랜딩 포트폴리오에 수백 개 깔린 "노션st 유기농 카페 톤" — 세련됐지만 이미 본 얼굴이라 기억에 안 남음. 2535가 공유하는 건 "예쁨"이 아니라 "나 이런 데 다녀"라는 정체성 신호인데 지금 안은 배경으로 물러나 스크린샷 찍을 이유가 없음. 클라이언트의 "쨍한 색" 본능은 정확했는데 "극단"이라며 통째로 죽이고 무채도 뒤 초록 점 하나로 합의 본 게 제일 아쉬움.
**리스크:** 250명 소규모의 최대 무기 "우리만의 색깔/괴짜스러움"을 대형 앱 정석 따라가다 스스로 지움.
**추천:** 그린 앵커 유지하되 쨍한 세컨더리 1색(감귤/코럴)을 "면"이 아닌 "포인트 폭발"로 상세·공유카드에만 과감히 투입해 공유 트리거 심기.

### 📖 한결 (에디토리얼/타이포)
**핵심:** 세리프 워드마크+Pretendard 본문 방향은 옳지만, 26px 워드마크·18px 책제목의 "소심한 세리프"로는 읽기 정체성이 표층에 그침. 디스플레이 스케일로 키워야 완성.
**근거:** 지금 세리프는 '장식'으로 소비되고 본문 Pretendard와 대비가 약해 잡지적 위계가 안 생김. 에디토리얼의 격은 색이 아니라 큰 활자·여백의 낙차에서 옴. 반려된 크림안이 올드했던 진짜 원인은 세리프가 아니라 '작은 세리프+아늑함'의 소극성 — 같은 실수를 스케일에서 반복할 위험.
**리스크:** Noto Serif KR + Fraunces 혼용 시 한글/영문 획 대비·굵기 톤이 어긋나 워드마크가 아마추어처럼 보임.
**추천:** 책제목·섹션 헤더를 세리프 28~40px 디스플레이로 끌어올리고, 한글은 Noto Serif KR 하나로 통일 + 자간 -1~-2%로 조여 모던 뉴트럴 톤 확정.

### 🛠 도윤 (디자인시스템/접근성)
**핵심:** CTA 명도대비는 통과하나 웜그레이 서브텍스트 대비 실패로 즉시 구현 불가. 전환 비용도 상당(63파일/437클래스).
**근거:**
- White on #127A5A = **5.31:1** ✓ (AA 통과)
- 서브텍스트 결함: `#6B7684` on #F9FAFB = **4.42:1** ⚠️(0.08 부족), `#8B95A1` = **2.91:1** ✗
- 현재 토큰 "Editorial Organic"(포레스트그린+테라코타+웜그레이+크림). A 전환 시 테라코타(Accent) 제거 → 상태/행동 구분용 보조색 공백 발생, 에러 레드와 충돌 여지
- 영향 범위: 437개 색상 클래스/63파일, CTA·배지·관리자 시각화 다수
**리스크:** 서브텍스트 대비가 임계값에서 진동(#6B7684 4.42:1) → 실기기 렌더링 따라 판정 불확실. 단일 그린은 상태/행동 색 구분 부족.
**추천:** ①서브텍스트를 #5A6B7A대로 진하게(또는 배경을 #F0F2F5로) 재검증 ②상태/행동 구분용 보조 악센트 1색 추가 ③토큰 마이그레이션은 회귀 테스트 포함해 계획.

## 라운드 2: 토론

### 상호 반박 & 보강
**🔥 민서 ↔ 🛠 도윤 (핵심 수렴):** 둘이 완전히 다른 출발점(문화적 공유가치 vs 기술적 상태구분)에서 **동일 결론 — "그린 단색만으론 부족, 쨍한 보조색 1개 필요"**에 도달. 민서는 공유 트리거로, 도윤은 상태/행동 구분+에러 충돌 회피로. 이 우연한 합치가 이번 패널의 최강 신호. 게다가 이건 클라이언트가 원래 끌렸던 "쨍한 색"을 '면=극단' 없이 되살리는 정확한 해법.

**🎨 지현 ↔ 🔥 민서:** 둘 다 "A는 아직 브랜드가 아니다"에 동의. 지현은 워드마크/심볼 부재로, 민서는 기억에 안 남는 제너릭함으로. 해법도 같은 곳을 가리킴 — 이름 언어유희(지독하게/독해) 심볼 + 소유되는 색.

**📖 한결 ↔ 🎨 지현:** 한결의 "디스플레이 스케일 세리프"는 지현의 "워드마크로 색을 소유"와 직결. 큰 세리프 워드마크가 곧 브랜드 소유 장치. 단 한결은 Noto Serif KR + Fraunces 혼용을 경고 → 워드마크는 한글 세리프 단일로.

**📐 태오 (독립 축):** 태오의 지적(상태 5종 CTA, "이번 주" 폴백)은 색/브랜드와 별개의 UX 축이지만, "보여야" 원칙상 반드시 별도 트랙으로 처리. 색 결정과 병행 가능.

### 핵심 논쟁점
1. **"정석 A"가 안전한가 지루한가** — 민서(지루/제너릭) vs 조사·정석(검증됨). → 합의: 아키텍처는 유지하되 민서의 처방(쨍한 보조색 포인트)으로 제너릭함 탈출.
2. **그린 단색 vs 그린+보조색** — 도윤·민서가 독립적으로 "보조색 필요"로 수렴 → 사실상 논쟁 종결, 보조색 도입으로 합의.

### 최종 합의
A안의 **구조(오프화이트+웜그레이+에디토리얼 세리프+Pretendard, 앵커 그린을 점으로)는 옳고 유지**한다. 그러나 현재 상태는 "잘 정돈된 UI 테마"이지 아직 "브랜드"가 아니며, 순수 그린 단색은 (a)제너릭하고 (b)상태/행동 색 구분이 부족하다. 따라서 **그린 앵커 + 쨍한 보조색 1색(감귤/코럴 계열)을 '면이 아닌 포인트'로 도입**해 클라이언트가 원래 끌렸던 "쨍함"을 절제된 방식으로 되살린다. 동시에 **이름 언어유희 기반 워드마크/심볼**과 **디스플레이 스케일(28~40px) 한글 세리프**로 그린을 브랜드 자산으로 소유시킨다. 접근성(서브텍스트 대비)과 UX 상태 분기는 별도 트랙으로 즉시 보정.

## 액션 아이템
1. **보조 악센트 1색 도입** — 감귤/코럴 계열 1색을 상세페이지·공유카드·핵심 순간의 '포인트'로만. 배경 면 사용 금지. (민서+도윤 합의)
2. **서브텍스트 대비 수정** — 웜그레이 서브텍스트를 #5A6B7A대로 진하게(또는 배경 #F0F2F5) 조정해 WCAG AA 4.5:1 확보 후 재검증. (도윤)
3. **디스플레이 세리프 스케일 업** — 책제목/섹션헤더를 28~40px 한글 세리프(Noto Serif KR 단일)로, 자간 -1~-2%. Fraunces와 혼용은 워드마크에서 배제. (한결)
4. **워드마크+심볼 1안 착수** — '지독하게/독해' 언어유희를 심볼로. 잉크 그린을 소유시켜 브랜드화. (지현)
5. **UX 상태 트랙 별도 명세** — 카드 CTA 5종 상태 분기 + "이번 주 없음/전부 마감" 폴백 빈 상태. (태오)
6. **토큰 마이그레이션 계획** — 437클래스/63파일 영향. 회귀 테스트 포함, 배포 정책(안정→운영자→회원)에 맞춰 단계화. (도윤)
