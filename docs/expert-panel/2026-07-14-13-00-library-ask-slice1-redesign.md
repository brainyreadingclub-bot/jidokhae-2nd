## 라운드 1: 독립 의견 (요약)

### 🎯 문지혜 (PM/PO)
- 최소 스코프 = 플래그 제거 + 모임 상세 진입점 + 4주 모니터링. Q2/Q4/Q5는 2조각 유보.
- Q2 제외(데이터 품질·60일 바깥 회원 차단), Q3 유지(비용0), Q4 보류(DB 변경), Q5 제외(4주 후), 도달경로 모임상세 포함.

### 🎨 이서린 (UI/UX)
- 3중 박스 적층·중복 입구·3중 문구가 인지 부하의 산. "영속 상태 inline"으로 재설계.
- Q2 No(계층화), Q3 제거, Q4 "완독"만 토글(읽는중 금지), Q5 포함하되 inline 컨텍스트 메뉴+실행취소 토스트. 소개 strip 제거.

### ⚛️ 강태오 (프론트엔드)
- Q3 저비용(15분), Q4-1 라벨만 저비용(DB 무변경)/Q4-2 3단 고비용(마이그레이션), Q5 삭제 라우트 중간(1h)·토스트 저비용(라이브러리 유무 확인), 도달경로 홈 저비용/모임상세 중간.

### 🔍 남기준 (QA)
- CRITICAL Top3: ① dismiss 영구성 + 60일 만료 겹침 ② Q2 빈상태 검색 제거 시 책 담기 완전 차단 ③ 담기 멱등 silent + 피드백 부재.
- 삭제 라우트 없음 = 오검색 책 영구 잔존. 배포 전 필수.

### 📊 정하람 (데이터)
- 분모/분자 정의는 정확하나, "노출됐는데 안 함"을 서버가 몰라 폐기 판정 불가.
- `book_asks.first_viewed_at`/`dismissed_at` 컬럼 추가 + `ask_strip_exposed` 계측 필수. 경로 확대 시 entry_point 태깅 필수(지표 조작 방지).

### 📣 백서준 (PMM)
- "개인 기록"만으론 동기 약함. 단, 투표 암시는 이서린·정하람 반박 수용해 철회. 동기는 타이밍(모임 직후)+담은 뒤 즉각 피드백으로.
- 카피: 헤드라인 "무슨 책 읽으셨어요?" 유지, 서브 "N월 정기모임 · 서재에 담아두세요", 버튼 "책 담기".

## 라운드 2: 토론

### 핵심 논쟁점
1. Q5(삭제+피드백) 1조각 포함 여부 — PM(제외) vs QA·UI·PMM(배포 전 필수). QA "첫날 문제" 우세.
2. 소개 strip 유지 vs 제거 — PM(유지) vs UI·PMM(제거/흡수). 인지 부하 논리 우세.
3. 동기의 원천 — PMM(투표 암시) → 토론 끝에 타이밍+피드백으로 수렴(PMM 후퇴).
4. 응답률 계측 — 전원 동의. 노출 기록 없으면 폐기 판정 불가. 숨은 필수 항목.

## 최종 합의
1조각의 진짜 결함은 UI 장식이 아니라 (A) 폐기 판정을 못 하는 계측 공백과 (B) 사용자를 막다른 상태에 가두는 3개 함정이다. 재설계 스코프는 "예쁘게"가 아니라 "측정 가능하고 막히지 않게".

① 소개 strip 제거(문구를 물어보기/서재 부제로 흡수) ② 빈상태 검색 유지·filled에선 collapsible(Q2 유일입구 강박 폐기) ③ 상태 2단 유지·라벨만 "읽는중↔완독"(DB 무변경) ④ 책 빼기(삭제) + 담은 뒤 유형별 토스트(added/already/실행취소) 1조각 포함 ⑤ dismiss soft화 + first_viewed_at/dismissed_at 기록 → 노출 계측 ⑥ 모임 직후 진입점 1개 추가 + 경로 파라미터 태깅. 회원 프레이밍은 끝까지 "개인 기록"만, 투표 암시 금지.

## 액션 아이템
1. 소개 strip(LibraryIntroStrip) 제거, 안내 문구 1곳씩만 흡수 (저비용)
2. 책 상태 라벨 "완독 표시→읽는중 / ✓완독" 변경, completed boolean 유지 (저비용)
3. 삭제 라우트 `/api/library/delete` 신설 + LibraryGrid inline "…" 메뉴 (본인 검증) (중간)
4. 담은 뒤 토스트: API가 result 'added'|'already' 반환 → 유형별 표시 (라이브러리 유무 확인)
5. book_asks에 first_viewed_at·dismissed_at 컬럼 + 노출 기록 + admin 3상태 집계 (중간, 북극성 전제)
6. dismiss soft화: 재노출 or 60일 내 수동 담기 경로 보장 (QA CRITICAL #1 해소)
7. 도달경로: 모임 직후 진입점 1개 + ask_strip_view에 entry_point 파라미터
8. 회원 카피 최종: 헤드라인 유지, 서브 "N월 정기모임 · 서재에 담아두세요", 버튼 "책 담기"
