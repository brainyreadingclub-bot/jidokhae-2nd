이 시안이 지킨 것

  • 바닥은 #FFFFFF. tg-50·neutral-50(둘 다 #F9FAFB)은 페이지 바닥으로 쓰지 않았습니다
  • 세리프 0 · 테두리 0 · 짙은 초록 면 0. 강조는 색이 아니라 크기가 맡습니다
  • 로그인은 fixed inset-0이 아닙니다. 스크롤하면 사업자 정보 푸터에 닿습니다 (PG 심사 항목)
  • 폼은 한 화면 · 칸 4개. 이메일을 뺐고, 지역이 마지막 칸입니다
  • 입력칸 글자 16px. 14px이면 iOS가 포커스할 때 화면을 확대합니다
  • 금액은 숫자만. 「원」·「₩」 없음
  • 문구는 채택된 셋만 바꿨습니다 — 환영 CTA 프로필 만들기 → · 넷플릭스 카피 대안 A · 전화번호 한 줄. 어미는 지금 문장을 그대로 따라갔습니다
