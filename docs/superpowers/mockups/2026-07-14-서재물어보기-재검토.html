안1 · 소개 strip 제거 (추천)

＋ 콜드스타트 박스 1개, X 1개 — 가장 깔끔
＋ "새 기능" 성격은 제목 밑 한 줄로 충분
－ "새로 생겼다"는 신설 강조가 약함

안2 · 소개 strip 유지

＋ 기능 신설을 명시적으로 알림(첫 노출 1회)
－ 박스 2개 + X 2개 잔존, 콜드스타트가 두 겹
※ 유지 시 문구는 반드시 "위치 안내"로(쌓여요 반복 금지)

250명 소규모라 소개는 초경량이어야 한다는 원칙(전면모달 금지)에 비추면 안1이 더 부합. 다만 "새로 생김"을 꼭 알리고 싶으면 안2.
