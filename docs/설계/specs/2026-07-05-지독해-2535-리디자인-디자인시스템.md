## 0. 목표와 원칙

기존 "Editorial Organic(딥포레스트그린 + 웜테라코타 + 크림)"을 폐기하고, 한국 2535(25~35세)를 끌어들이는 방향으로 전면 전환.

**전환 근거(조사 검증):** 2026 한국 2535 정석 = **"앵커 1색을 '점'으로 + 절제된 뉴트럴 + 에디토리얼 세리프"** (토스 #3182f6 / 당근 #FF6F0F 단일 앵커 패턴). 따뜻함·크림 = 올드, 형광펜·다색 = 유치, 풀채도 색면 = 극단. → 쨍한 1색을 **면이 아니라 점**으로 쓰는 게 프리미엄.

**세 원칙(서비스 개요 계승):** 쉬워야(3초 확인/3클릭 신청) · 모여야 · 보여야(상태 명확).

## 1. 색상 시스템

### 1-1. 앵커색 — 잉크 그린 `#127A5A`
브랜드 앵커. **CTA·활성상태·신청완료·가격 아님(→ 뉴트럴)·'점'에만.** 화면에서 그린이 하나만 튀어야 시선이 CTA로 간다.

| 용도 | HEX |
|---|---|
| 앵커 (CTA 버튼, 활성 요일, 완료 ✓, 링크) | `#127A5A` |
| 진그린 태그 텍스트 (모집중) | `#0d5c43` |
| 연그린 태그 배경 | `#E3F2EC` |
| 연그린 카드 배경 (내 것 하이라이트 **단건만**) | `#F3FAF6` |
| 연그린 보더 | `#CDE9DB` |

> ⚠️ **그린 = 점 규칙:** 연그린 카드 배경을 여러 장 쌓으면 그린이 '면'으로 번져 앵커 특권이 죽는다. "내가 신청한 모임" 하이라이트 **1건**에만 연그린 카드를 쓰고, 목록 카드는 흰 배경 유지.

### 1-2. 포인트색 — 감귤 코럴 `#F4552A`
'순간'에만 폭발. **마감임박 · D-day 임박(D-3 이하) · 잔여 1자리 같은 긴박함에만.** **배경 면엔 절대 사용 금지**(유치함 방지).

| 용도 | HEX |
|---|---|
| 마감임박 태그 채움 배경 (흰 텍스트) | `#F4552A` |
| 마감임박 D-day/잔여 텍스트 | `#F4552A` |
| 연코럴 보더 (마감임박 카드) | `#FADFD5` |

> ⚠️ 상시 노출되는 정보(참가비 등)에 감귤을 쓰면 안 된다. 감귤은 희소해야 의미가 산다.

### 1-3. 뉴트럴 (웜그레이 계단)
크림 아님. 오프화이트 + 웜그레이.

| 용도 | HEX | 비고 |
|---|---|---|
| 배경 (오프화이트) | `#F9FAFB` | |
| 카드 배경 | `#FFFFFF` | |
| 카드 보더 | `#E5E8EB` | 보조: `#E9ECF0` `#EEF1F4` `#F0F2F5` |
| 제목 (니어블랙) | `#191F28` | |
| 서브텍스트 | `#5A6B7A` | WCAG AA (오프화이트 위 ≥4.5:1) |
| 뮤트 텍스트 | `#6B7684` | **뮤트는 이 값 단일 토큰.** `#8B95A1`은 대비 2.9:1 실패 → ≥12px 또는 아이콘 stroke에만, 소형 본문 금지 |
| 비활성/네비 | `#B0B8C1` | 큰 텍스트/아이콘만 |

## 2. 타이포그래피

**핵심 경계:** 세리프(Noto Serif KR)는 **"읽는 것"에만** — 워드마크·히어로 헤드라인·책/모임 제목. 그 외(본문·UI·메타·금액·버튼·태그)는 전부 Pretendard. 세리프를 아무 데나 뿌리면 세리프의 프리미엄 효과가 죽는다.

### 2-1. Noto Serif KR (디스플레이 세리프) — 500/600/700/900
| 요소 | 크기(px) | weight | 자간 |
|---|---|---|---|
| 워드마크 | 25~34 | 900 | -1.5~-2% |
| 히어로 헤드라인 | 18~29 (조건부) | 700 | -0.9~-1.3% |
| 모임 상세 책제목 | 32 | 900 | -1.6% |
| 카드 책제목 | 16~18 | 700 | -0.6% |

### 2-2. Pretendard — 본문·UI·금액
- 본문/메타: 11.5~12.5px
- 금액: **Pretendard + `tabular-nums`(`font-feature-settings:'tnum'`)**. 세리프·모노 금지.

## 3. 금액 표기 규칙 (확정)

1. **단위 없이 숫자만** — `10,000`. **'원'·`₩` 절대 금지.** (가격 프레이밍 심리: 단위가 붙으면 지불의 고통↑, 금액이 커 보임. 사용자 확정 규칙. 실코드 `formatFee()`도 이미 숫자만 반환 → 정합. 메모리 `feedback_price_no_won_unit`.)
2. **폰트** — Pretendard tabular-nums. 세리프 금지.
3. **색** — 무채색만. **그린·감귤 둘 다 금지**(그린 CTA 옆 초록 금액 = 그린 '면'화 → 앵커 죽음). 강조는 색이 아니라 명도·두께로만.
   - **예외(긍정·희소 신호, 상세 정보행에 한함):** `무료`, 스텝 **할인가**는 잉크그린 허용. 근거 — 상세 정보행은 CTA와 비인접이라 면화가 아니고, '이득'을 색으로 알리는 게 UX상 유효. 목록 카드엔 애초에 금액이 없으므로(§4-1) 이 예외는 상세에서만 발생.
4. **위치별:**
   - **모임 카드: 참가비 미표기.** 금액은 상세에서만 노출한다(2026-07-07 확정, §4-1 참조). 카드 CTA row에는 가격 없이 CTA/태그만.
   - 상세 정보행(CTA 비인접): `14px / 600 / #191F28` (결제 앵커, 명도로만 강조). 라벨 "참가비"는 `12px / 500 / #6B7684`
   - 스텝 할인 대상: 상세에서 정가 취소선(`12px / #B0B8C1`) → 할인가(`14px / 800 / #127A5A`) + "스텝 −50%" 태그. **카드=상세 동일 계산(`getDisplayFee`)** 이지만 카드엔 미표기하므로 노출은 상세 1곳뿐.
5. **무료:** `0` 아님 → **`무료`**. 상세행에서만 예외적으로 잉크그린 허용 가능(무료=긍정=희소).

## 4. 컴포넌트 & 위계

### 4-1. 카드
흰 배경 + `#E5E8EB` 보더 + radius 16 + padding 15. 카드 내 시각 위계:
> 제목 17/700(세리프) **>** CTA 버튼 12/700(§4-2-1) **>** 상태 태그 11/800(§4-3) **>** 날짜·인원 11.5~12/500~600

**그린 = 점 규칙, 카드 레벨 금지 2종(2026-07-07 확정):**
- ❌ **카드 좌측 컬러 세로선 금지.** 카드마다 그린(또는 상태색) 좌측선을 두면 목록 전체에 그린이 '면'으로 번져 앵커 특권이 죽는다. 상태는 우상단 **태그**로만 표기(Editorial Organic의 4px 좌측 컬러선은 폐기).
- ❌ **카드 날짜 pill 그린 배경 금지.** 날짜 메타는 무배경 뉴트럴(`#4E5968`) + 흐린 캘린더 아이콘. 카드마다 반복되는 그린 pill = 면화.

**참가비 미표기(2026-07-07 확정):** 카드에는 금액을 넣지 않는다. 근거 — (1) 거의 균일 소액(대부분 10,000)이라 가격이 진입장벽/결정 동인이 아니고, (2) 카드에 가격을 넣으면 스텝 할인가·정원 마스킹(3명 미만)과 얽혀 카드/상세 숫자 불일치 등 정합성 리스크가 생긴다. 목록은 '무슨 책을 읽나'에만 집중시키고, 금액은 결정 순간(상세)에서 처음 노출한다(마찰 지연). C안(카드에 정가 취소선→내 금액 표시, `getDisplayFee`로 카드=상세 일치)도 검토했으나 목록 미니멀리즘을 우선.

### 4-2. CTA 위계 (부정 액션 강등)
- **Primary(신청/확정):** 그린 solid, 흰 텍스트, radius 8~11.
- **Destructive(취소):** **고스트** — 흰 배경 + 회색 텍스트(`#5A6B7A`) + `#DDE2E7` 보더. 취소를 primary처럼 그린 solid로 두면 실수 탭 유발.

### 4-2-1. 목록 카드 CTA 상태 분기 (2026-07-07 확정)
"전체 일정" 목록 카드의 우하단은 **모임의 공개 정원 상태**로 버튼/태그를 가른다. **"액션이 가능한가"** 기준 — 액션 불가 상태까지 버튼(초록/박스)으로 두면 초록·박스가 목록에 반복돼 면화된다.

| 공개 상태 | 카드 우하단 | 형태 |
|---|---|---|
| 모집중 | `신청하기` | **그린 solid 버튼** |
| 마감임박(정원 초과·대기 가능) | `대기 신청` | **고스트 버튼**(흰 배경 + 그린 텍스트 + `#CDE9DB` 보더) |
| 마감(정원 참) | `마감` | **뮤트 태그**(버튼 아님, `#F0F2F5` / `#6B7684`) |

- **버튼은 상세로 이동**한다(카드에서 인라인 결제 안 함). 라벨이 "결제 완료"를 약속하지 않게 유지 — 신청하기 탭 → 상세 → 결제.
- **본인이 이미 신청한 모임(confirmed/pending_transfer/waitlisted)은 이 표 대상 아님.** 전체 일정에서는 제외되고(부모 CLAUDE.md 중복 방지), 홈 "내 모임" 섹션에서 상태 신호와 함께 표시 — 신청완료/입금대기는 초록 스트립(§4-5·§5), 대기중은 뉴트럴 뱃지(§5).
- 구현 주의: 실제 카드는 전체가 `<Link>`라 내부에 `<button>` 중첩 불가 → 카드 마이그레이션 시 "본문 링크 + 별도 CTA"로 링크 구조를 분리해야 한다. 스텝 할인가·마스킹 회귀 테스트 필수.

### 4-3. 태그
`11px / 800 / radius 6`. **배경 있는 태그 안엔 앵커 점(●) 넣지 않음**(점은 배경 없는 곳에서만 특권).

### 4-4. D-day
위치·형태 **통일**, 색만 임박도로 분기 — D-3 이하 감귤 `#F4552A`, 여유는 그린/뮤트. 같은 정보를 카드마다 다른 시각 언어로 쓰지 말 것.

### 4-5. 신청완료 스트립 (본인)
inline ~40px 높이. 연그린 배경 `#F3FAF6` + `#CDE9DB` 보더 + ✓ 그린 동그라미 + 인사 메타 + D-day. 컨테이너 중첩 금지(Refactoring UI·Linear 패턴).

### 4-6. 텍스처
미세 그레인(SVG fractalNoise, **opacity ≤ .2**, multiply) — 프리미엄감. `.3` 이상이면 '오래된 종이'로 읽혀 올드해짐(2026-07-07 패널). 상한 .2 엄수.

## 5. 상태 시각 언어

| 상태 | 태그/신호 | 색 |
|---|---|---|
| 모집중 | "모집중 O/N" 태그 | 연그린 배경 `#E3F2EC` / 텍스트 `#0d5c43` |
| 마감임박 | "마감임박 O/N" 채움 태그 + D-day·잔여 | 감귤 `#F4552A` / 흰 텍스트 |
| 신청완료(본인) | ✓ + 연그린 태그·스트립. **이 뷰에선 마감임박 톤다운**("O/N명 함께해요" 중립) | 그린 `#127A5A` |
| 대기중 (waitlisted) | "대기 N번" 뱃지 + 고스트 `대기 취소하기` | **뉴트럴 회색**: 배경 `#EEF1F4` / 텍스트 `#5A6B7A`. 그린(확정)·감귤(긴박) 어느 쪽도 아님 — 확정과 명확히 구분 |
| 입금대기 (pending_transfer) | **초록 "신청 접수됨" 스트립**(신청완료와 동등 안심) + **뉴트럴 입금 안내 박스** + 입금자명("M/D 닉네임", 복사 가능) + **입금 기한** 명시 | 스트립=그린 `#127A5A`, 안내 박스=뉴트럴, 경고 점만 코럴 `#F4552A`(면 아닌 점) |

> **입금대기 카피 확정(2026-07-07):** 헤드라인은 "신청 완료"가 아니라 **"신청 접수됨"** — 아직 입금 전이라 '완료'는 거짓 정보(입금 안 하게 만듦). 입금 기한을 반드시 함께 표기. 단, 운영자 입금 확인 지연을 감안해 회원 안심용으로 스트립 자체는 확정과 동일한 초록 톤 유지(정합: `pending_transfer` 본인 = confirmed 동등 취급, 부모 CLAUDE.md 참여자 명단 정책과 일치).
>
> **대기중 색 근거:** 대기는 '확정 아님 + 긴박함도 아님'이라 그린/감귤을 쓰면 오해. 무채색 뉴트럴로 "보류" 뉘앙스. `phones-missing.html` 대기중 화면과 일치.

## 6. 접근성

- 소형 본문 대비 WCAG AA 4.5:1 — 서브 `#5A6B7A`, 뮤트 `#6B7684`. `#8B95A1`은 소형 텍스트 금지.
- 타이포 하한: 태그 11px, 서브 11.5~12px.
- 터치 타깃 최소 44px(프로필 '수정' 등 작은 버튼 주의).
- 기호 의존 지양: navbar 등은 실제 선형 아이콘 셋으로(임시 `✦◷◎` 교체 예정).

## 7. 반려 히스토리 (안티패턴 — 다시 제안 금지)

- 따뜻함/크림/테라코타 = 올드 (현 스택 핵심 문제)
- 형광펜/다색 = 유치 · 다크모드 = 밍밍 · 풀채도 색면 = 극단
- 페이퍼+약한 포인트(힙1) = 별로
