# 전면 개편 1단계-B: 5탭 UI × 토스 스킨 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `next_ui` 플래그 뒤에 5탭(홈·모임·이야기·서재·나) 화면과 발제 스레드·모임 자리 모드·알림함 UI를 토스 스킨으로 만든다. 1단계-A의 lib/API를 소비한다.

**Architecture:** 새 라우트 그룹 `(next)` — 자체 레이아웃이 플래그를 검사해 OFF면 `/`로 보낸다. 기존 `(main)`·`(admin)` 라우트는 **무변경**(알림톡 구경로 보존). 화면은 "데이터 조립 = 서버 페이지 / 표현 = props 컴포넌트"로 분리해 **`policy/preview-next` 임시 페이지 + Playwright**로 로컬 검증한다(OAuth 제약 우회 — feedback_gated_layout_temp_preview 패턴).

**Tech Stack:** Next.js 16 App Router · Tailwind v4(`@theme inline` 토큰 추가) · 1단계-A lib

**전제:** 브랜치 `feat/next-phase1a` 이어서. 스킨 기준 = [토스 18화면 시트](../mockups/2026-08-16-토스-전체-18화면.html). 검증 규칙: 커밋 전 `npx tsc --noEmit`, 태스크 묶음마다 `npm run prelaunch`.

### Task B2: (next) 레이아웃 + NextNav + 벨

- [ ] `NextNav.tsx` — client, 5탭(홈 `/home`·모임 `/meet`·이야기 `/talk`·서재 `/shelf`·나 `/me`), 기존 BottomNav 구조 복제 + 토스 색(`text-tg-900` on / `text-tg-400` off), 아이콘은 18화면 시트의 SVG 5종
- [ ] `NotificationBell.tsx` — server, `unreadCount(userId)` > 0이면 주황 점, `/me/notifications` 링크
- [ ] `(next)/layout.tsx`:

```tsx
import { redirect } from 'next/navigation'
import { isNextUiEnabled } from '@/lib/next-ui'
import { getUser } from '@/lib/auth'
import NextNav from '@/components/next/NextNav'
import NotificationBell from '@/components/next/NotificationBell'

export default async function NextLayout({ children }: { children: React.ReactNode }) {
  if (!(await isNextUiEnabled())) redirect('/')
  const user = await getUser()          // 미들웨어가 미로그인 처리
  return (
    <div className="min-h-dvh bg-white text-tg-900">
      <header className="mx-auto flex h-12 max-w-screen-sm items-center justify-between px-5">
        <span className="text-[17px] font-extrabold tracking-tight text-brand-deep">지독해</span>
        {user && <NotificationBell userId={user.id} />}
      </header>
      <main className="mx-auto max-w-screen-sm px-5 pb-24">{children}</main>
      <NextNav />
    </div>
  )
}
```
