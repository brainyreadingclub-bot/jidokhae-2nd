# 홈 회원 상태별 카드 — 필요한 데이터 조건 메모 (구현 금지 · 시안 전)

> 2026-10-16 · 빌드2 · 결정: `검토문서/DECISIONS.md` 2026-10-16 「홈 — 회원 상태별로 맨 위 강조 카드가 바뀐다」(시안 확인 전 구현 금지) · 보관함 I-018(가입만 한 회원에게 신청 안 한 이유 묻기) · I-004(최근 담긴 책 조건)
> **새 칸 없이 지금 표로 판정된다.** 필요한 것은 판정 규칙 4개의 기준 숫자(아래 🟨)와 「이유 묻기」 답을 담을 자리뿐이다.

## 1. 판정에 쓰는 것 (실측 칸 이름, 2026-10-16)

- `profiles.profile_completed_at` — 가입 끝(프로필 설정 마침). 이것이 비어 있으면 홈이 아니라 입장 관문이 먼저 뜬다
- `registrations.status` ∈ `confirmed`·`pending_transfer` = 「참여」(코드 `PARTICIPATED_STATUSES`와 같은 기준) · `waitlisted`는 참여 아님
- `meetings.date`(KST 날짜) · `meetings.status = 'active'`(삭제된 모임 제외) · `meetings.meeting_type`
- 지난 참여 = 위 참여 상태 + 모임 날짜 < 오늘(KST). 출석은 기록하지 않는다(참여 = 결제 + 모임일 경과)

## 2. 상태 판정 — 위에서부터 먼저 맞는 것 하나

| 순서 | 상태 | 조건 | 맨 위 카드 |
|:-:|---|---|---|
| 0 | **모임 당일** | 오늘 날짜 모임에 참여 상태 신청이 있다 | 그 모임 「모임 자리 모드」로 바로 들어가는 카드(결정 문장) |
| 1 | (다가오는 신청 있음) | 오늘 이후 모임에 참여 상태 신청이 있다 | 지금의 「내 모임」 카드 그대로 — 상태 카드보다 위 🟨 |
| 2 | **가입만 함** | 프로필 마침 + 참여 상태 신청이 **한 번도 없음**(지난·다가오는 모두) | 첫 모임 권하기 + 「신청 안 한 이유」 질문 1개(I-018) |
| 3 | **오래 안 옴** | 마지막 지난 참여가 **60일 🟨** 넘게 전 | 다시 오기 카드 |
| 4 | **단골** | 최근 **90일 🟨** 안 지난 참여 **3회 🟨** 이상 | 단골 카드 |
| 5 | **한 번 와 봄** | 지난 참여가 정확히 1회(그리고 3에 안 걸림) | 다음 모임 카드 |
| — | 남는 무리(가끔 옴) | 2회 이상인데 4·3 어디에도 안 걸림 | 🟨 「한 번 와 봄」 카드를 같이 쓸지 정해야 함 |

**2026-10-16 실측(읽기 전용, 위 기준 그대로)** — 프로필 마친 회원 155명 중 가입만 함 75 · 오래 안 옴 27 · 단골 18 · 한 번 와 봄 13 · 가끔 옴 22 (합 155). 따로 다가오는 신청 있음 19명(위 상태와 겹침).
- 현황판 목표 2의 「신청 확정이 한 번도 없는 가입자 88명」과 다른 이유: 저쪽은 프로필을 안 마친 가입자까지 센다(세는 법이 다름 — 숫자 비교 금지)
- ⚠️ 지난 모임의 `pending_transfer`(입금 확인 안 된 옛 건, 결정대기 「통장 대조」)도 「참여」로 센다 — 지금 코드 기준과 같게 둔 것. 통장 대조 결과에 따라 몇 명은 「가입만 함」으로 옮겨질 수 있다
- 🟨 모임 종류: 참여 횟수는 운영진 모임 전부(정기·토론·작업실·별책부록)로 셀지, 정기만 셀지. 권고 — **전부 센다**(누구든 왔으면 온 것). 「첫 모임」 알림톡 판정만 정기 기준

## 3. 「신청 안 한 이유」 묻기 (I-018) — 담을 자리

- 저장처 권고: **공통 기록표 `app_events`**(2026-10-14 결정 「기능마다 기록표를 만들지 않는다」) — `event = 'home_no_apply_reason'`, `props = { reason, from: 'home' | 'brand_message' }`. 새 표 없음
- 한 회원 한 번 답하면 카드에서 질문을 감춘다(같은 표에서 그 회원의 기록 유무로 판정) · 「나중에」 3번 누르면 감춘다 🟨
- 선택지(초안, 시안 때 확정): 시간이 안 맞아요 · 가까운 지역 모임이 없어요 · 혼자 가기 어색해요 · 어떤 모임인지 잘 몰라서요 · 참가비가 부담돼요 · 그냥 둘러보는 중이에요 · 기타(짧게)
- 브랜드 메시지(채널 친구)로 같은 질문을 보내면 버튼이 홈의 같은 카드로 오게 한다(`from = 'brand_message'`)

## 4. 「온기 칸」 — 보일 조건

- 회원 한 줄 소감: 모임 후기에서 「공개해도 좋아요」를 켠 것만, 운영자·본인이 내린 것 제외, 최근 180일(후기 DB 계획서 기준)
- 최근 담긴 책: 한 사람당 1~2권, **서로 다른 회원 5명 이상**일 때만(I-004) — 아니면 칸 전체를 숨긴다
- 둘 다 기준에 못 미치면 칸을 숨긴다(빈칸·「아직 없어요」를 띄우지 않는다)

## 5. 시안 때 정할 것 (🟨 모음)

1. 기준 숫자 셋 — 오래 안 옴 60일 · 단골 90일 안 3회. 설정값으로 둘지
2. 「가끔 옴」(22명) 무리에 어떤 카드를 보일지
3. 다가오는 신청이 있으면 상태 카드를 숨길지(권고: 숨김 — 맨 위 카드는 하나)
4. 「나중에」 몇 번이면 질문을 감출지
