# 모임 상세 화면 벤치마킹 — 다른 서비스는 「갈지 말지」를 어떻게 돕나

**작성일** 2026-09-21 · **부서** 디자인(조사) · **종류** 자료 수집 (시안 아님)
**이미지** `docs/agent-team/조사/2026-09-21-모임상세-벤치마킹/` (25장, 전부 이 조사 중 직접 캡처)

---

## 5줄 요약

1. **거의 모두가 사진 → 제목 → 사실 3개(언제·어디서·몇 명) → 신청 순서**다. 그런데 **넷플연가는 사진을 제목 아래로 내렸다** — 우리처럼 사진이 약한 서비스가 쓸 수 있는 유일한 전례다.
2. **금액은 대부분 화면에 한 번만 나온다.** 그 한 번을 **아래 고정 바에 두는 쪽**(에어비앤비·이벤트브라이트·밋업·남의집)과 **본문 위쪽에 크게 두는 쪽**(트레바리·문토·프립)으로 갈리는데, **버튼 안에 금액을 넣은 곳은 한 곳도 없었다.** 우리는 지금 버튼에 넣고 있다.
3. **「몇 자리 남았나」를 금액 바로 옆에 붙이는 것이 표준에 가깝다.** 밋업은 고정 바에서 `Free / 0 spots left`, 프립은 `39,000원 · 2개 남음`, 루마는 `남은 자리 3개`, 에어비앤비는 날짜마다 `10자리 남음`.
4. **환불 규정을 본문 위쪽에 문장으로 펼쳐 놓은 곳은 없었다.** 에어비앤비는 **「무료 취소」 칩 하나**로 줄이고, 프립·넷플연가는 **맨 아래 표**로 내린다. 우리 화면은 정보 칸 바로 밑에 두 줄로 펼쳐져 있다.
5. **얼굴 사진 없이 「누가 오는지」를 보여주는 방법이 이미 세 가지 있다** — 트레바리는 **만화 아바타 + 신청자 통계 도넛**, 문토는 **닉네임 + 한 줄 소개 카드**, 당근은 **닉네임 + 동네 + 한 줄**. 우리 제약(실명·얼굴 금지)에 그대로 맞는다.

# 정리

## 거의 모두가 똑같이 하는 것 (공통 패턴 5개)

**① 「언제 · 어디서 · 몇 명」 세 가지는 반드시 제목 근처에, 아이콘과 함께.**
표(라벨 왼쪽 / 값 오른쪽)를 쓴 곳은 트레바리 하나뿐이었다. 나머지는 **아이콘 + 한 줄**을 세로로 쌓거나(문토·밋업·에어비앤비·루마), **가로 3칸**으로 놓는다(넷플연가). 우리 화면의 「언제/어디서/참여/참가비」 회색 표는 **12곳 중 1곳만 쓰는 방식**이다.

**② 금액은 화면에 한 번.** 문토(2번)·남의집(날짜 카드마다) 빼고는 전부 한 번뿐이었다. **그리고 버튼 안에 금액을 넣은 곳은 단 한 곳도 없었다.**

**③ 「남은 자리」를 금액 근처에 붙인다.**
밋업 `Free / 0 spots left` · 프립 `39,000원 · 2개 남음` · 루마 `남은 자리 3개` · 에어비앤비 날짜별 `10자리 남음` · 넷플연가 `⏰ 1자리 남음` · 이벤트브라이트 `FEW TICKETS LEFT`(제목 위) · 트레바리 `마감임박`.
**숫자 하나(`5/12명`)만 놓고 끝낸 곳은 없었다.** 전부 「서둘러야 하나」까지 말해준다.

**④ 환불 규정은 위쪽에 두지 않는다.** 에어비앤비는 칩 하나(`무료 취소`)로 줄였고, 프립·넷플연가·문토는 **맨 아래 표**로 내렸다. **결정하는 자리에 규정을 펼쳐 둔 곳은 한 곳도 없었다.**

**⑤ 「이 모임 믿어도 되나」에 답하는 칸이 따로 있다.**
형태는 달라도 전부 갖고 있다 — 진행 횟수(`241회 진행`·`399 events`), 별점(`4.8 ★ 59 reviews`), 후기 개수, 최근 활동(`2시간 전 활동`), 인증 배지(`남의집 인증`·`슈퍼호스트`).
**우리 화면에는 이 칸이 아예 없다.**

1. 🥇 **아래 고정 바 왼쪽에 「금액 / 남은 자리」를 쌓고, 버튼에서는 금액을 뺀다.** (밋업 `Free / 0 spots left`가 그대로 본보기) — 지금 우리는 `신청하러 가기 · 12,000`으로 금액을 버튼에 넣었는데, **12곳 중 버튼에 금액을 넣은 곳이 하나도 없었다.**

5. **「참가비 12,000이 어디 쓰이나」 두 줄.** (문토) — 대관료·다과 등. 숫자를 납득시키는 가장 싼 방법이다.

- **당근 모임 회차 상세**: 앱 전용.
- 각 서비스의 **결제 단계 화면**(금액이 한 번 더 나오는 자리)은 로그인이 필요해 보지 않았다. 프립만 신청 시트가 로그인 없이 열려서 확인했다.
