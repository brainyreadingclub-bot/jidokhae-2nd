## 0. 먼저 — 이 목록을 만들다 드러난 것

🔴 **켜는 날에 나갈 내용물이 우리가 생각한 것과 다르다.** 개편 화면 코드 **45파일이 `main`에 없고 열린 PR도 없다.** 런북의 머지 목록(`#50 → #49 → #53`)에 이것이 빠져 있다.

**그래서 이 목록의 1번은 기능이 아니라 「무엇을 내보낼 것인가」다.** 그게 정해지기 전까지 나머지 항목의 일정은 의미가 없다.

## A. 회원이 겪는 것 — 안 하면 켜면 안 된다

| # | 무엇 | 안 하면 회원이 겪는 일 | 누가 |
|:--:|---|---|---|
| A1 | 🔴 **개편 화면 45파일을 내보내는 경로 만들기** | 스위치만 켜지고 새 화면은 안 나간다. 모임을 누르면 옛 화면으로 떨어지고 **결제 전에 환불 규정을 못 본다** | 제품기획(머지 계획) → 개발·운영 |
| A2 | 🔴 **5탭에 로그아웃 + 약관·개인정보·환불정책·사업자정보 넣기** | **로그아웃을 못 한다.** 약관도 못 본다 — 법적 문제 | 디자인(자리) → 개발·운영 |
| A3 | 🔴 **신규 회원 첫 화면에 할 것 하나 두기** | 가입하고 들어왔는데 누를 게 없다 | 디자인(시안) → 대표님 → 개발·운영 |
| A4 | 🔴 **토론모임 자격 잠금 + 끄는 스위치** | 한 번도 안 온 사람이 결제한다 → **돈 받고 돌려드려야 한다** | 대표님(예외 여부) → 개발·운영 |
| A5 | 🟡 **옛 화면으로 넘어가는 3곳** (서재·신청 내역·프로필) | 딴 앱처럼 보인다. 조사 권고 = **내용은 그대로 두고 주소만 5탭 안으로**(시안 불필요, 1~2일) | 개발·운영 |
| A6 | 🟡 **「물어보기」 알림톡 버튼이 옛 화면으로** | **가장 자주 밟히는 길.** 모임 오신 분 전원에게 매번 나간다. 권고 = 주소만 새 화면으로 넘겨보내기(재심사 불필요) | 개발·운영 |
| A7 | 🟡 **눌러도 갈 데 없는 버튼 15개** | 눌렀는데 아무 일도 안 일어난다. ⚠️ **3주 전 숫자 — 다시 세야 한다** | 개발·운영 |
| A8 | 🟡 **토론모임이 옛 홈·비로그인 목록에 뜸** | 엉뚱한 곳에 노출. 지금 안 터진 건 데이터가 0건이라서다 | 개발·운영 |
| A9 | 🟡 **「신청 확정」 알림이 안 쌓임** | 알림함이 비어 보인다. 문구·자리는 다 있는데 만들어 넣는 코드만 없다 | 개발·운영 |
| A10 | 🟡 **책 주문 마감 안내 문구 없음** | 언제까지 신청해야 책을 받는지 모른다 (첫 토론모임 D-7 전) | 디자인 → 개발·운영 |

## 순서

**A1이 먼저다.** 무엇을 내보낼지 정해져야 나머지가 그 위에 얹힌다.

그다음은 **대표님 확인이 필요한 것부터**(D1 → D4). 만드는 시간보다 **답을 기다리는 시간**이 일정을 지배한다.

대표님 답을 기다리는 동안 개발·운영은 **확인이 필요 없는 것**을 먼저 끝낸다 — A5·A6·A8·A9, B1·B3, C1.

마지막에 전부 합쳐 **미리보기에서 실제로 눌러보며** 확인한다.
