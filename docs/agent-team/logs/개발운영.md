- 진짜 base로 재면 → 겹치는 게 없다 → 충돌 0

🟨 문서총괄이 실제로 어떤 명령을 썼는지는 그 세션 기록을 못 봐서 확인 못 했다. **같은 증상을 내는 조건을 찾은 것**이지 그 명령을 썼다는 증거는 아니다.

**🟨 쓰기 가드 오탐 2건 — 재현 실패, 원인이 가드가 아니다**

관리자가 막혔다는 두 명령(`git show ...|grep`, `sed -n '19p' ...`)을 **내 세션에서 그대로 돌렸더니 둘 다 통과**했다. 가드 소스(`.claude/hooks/manager-write-guard.mjs`)를 읽어보니 **이 둘을 물 토큰이 없다** — `BASH_WRITE_TOKENS`에는 `sed -i`는 있어도 `sed -n`은 없고 `git show`도 없다(`:66-71`), `REDIRECT_TO_FILE`(`:64`)은 파일로 나가는 `>`만 본다.

**진단: 권한 허용목록 미스일 가능성이 높다.** `.claude/settings.local.json`에 `deny`·`ask` 규칙이 **하나도 없고** `allow` 194건 중 **`git show`도 `sed`도 없다.** 허용목록에 없는 명령은 세션 권한 모드에 따라 막히고, 그건 훅이 아니라 **권한 시스템이라 세션마다 다르게 동작한다** — 내 세션에서 통과한 것도 그 설명과 맞는다.

**권고: 가드를 고치지 않는다.** `16121af`가 잡은 오탐 3건은 정규식이 실제로 잘못 물었던 것이고, 이번엔 **물 수 있는 토큰 자체가 없다.** 잘못된 원인에 손대면 가드만 느슨해진다. 대신 allow에 두 줄 추가를 §6-8로 올렸다(`.claude/**`는 관리자 소관).

**왜 그렇게 했는가**

- **`merge-tree`를 더 안 돌린 이유** — 관리자 지시이기도 하고, 실제로 **이 도구는 base를 어떻게 잡느냐로 답이 갈린다**는 게 이번 원인이었다. 같은 도구로 한 번 더 재면 세 번째 값이 나올 뿐이다. **실제 머지가 유일한 심판**이다
- **경로 B도 굳이 돌린 이유** — A만 통과해도 결판은 나지만, **두 경로의 tree가 같은지**를 봐야 "선택 기준이 내용이 아니라 롤백 단위"라고 말할 수 있다. 실제로 같았다

- **`npm run prelaunch` 미실행** — 머지된 조합을 검사하려면 체크아웃이 필요한데, 작업 트리에 **다른 세션의 미커밋 변경 4건**(`VOICE.md`, `DESIGN_TOKENS.md`, `공통규약.md`, `DECISIONS.md`)이 있어 건드리지 않았다(§7). 대신 이 미검증 자체를 위험 ④로 올렸고, import·호출부 인자 일치는 손으로 확인했다
- **prod SQL 쓰기 안 함** — 마이그레이션·플래그 INSERT 전부 승인 대상. 조회만 했다
- **`npx tsx scripts/*` 실행 안 함** — 실발송 위험
- **Solapi 콘솔 미확인** — 외부 SaaS. `NEW_MEMBER_WELCOME_V2`·`BOOK_ASK` 본문 변수는 **"확인 필요"로 남겼다.** 특히 WELCOME은 대조표에 변수 목록 자체가 없어(코드가 없던 시절에 쓰임) **7종 중 유일하게 대조가 안 된 칸**이다
- **Vercel env 현재 값 미확인** — 대시보드 접근 안 함. V1인지 V2인지 확인 필요로 남겼다
- 임시로 만든 `refs/remotes/pr/*` 3개는 조사 후 **삭제했다.** 저장소 상태를 처음 그대로 돌려놨다
