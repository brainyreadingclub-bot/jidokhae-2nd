**왜 그렇게 했는가**

- **`main` 기준으로 판정했다.** 현재 체크아웃된 `feat/agent-team`이 PR #56·#57 이전에서 갈라져 `DECISIONS.md`가 4행 뒤처지고 런북이 아예 없었다. 브랜치 트리만 보고 "런북이 없다"고 썼으면 오탐이었다. 이 교차 상태 자체도 항목으로 올렸다(부서들이 이 트리를 읽는다)
- **"이미 알려진 것"을 무조건 빼지 않았다.** 프로필 §알려진 미해결에 있는 것(알림 union 4중 정의, 재발송 불가, 호칭 불일치)은 새 발견으로 보고하지 않았다. 다만 품질 부서 2026-08-14 리포트가 지적한 것 중 **4일 지나도 안 고쳐진 것**(C2 마이그레이션 미커밋, W12-b 메뉴 7개, W12-c lib 누락)은 "경과"를 붙여 남겼다 — 그 리포트는 프로필의 면책 목록이 아니고, 방치 기간이 판단 근거가 된다
- **의도 확인(규약 §1)을 거쳤다.** `pending_transfer` 동일 표시, `attended` 미사용, TossPayments 잔존, 토큰 3명 마스킹은 프로필 §의도된 설계라 지적하지 않았다. 다만 `attended`는 보관소 멤버십 노트의 "체크인 차감"과 충돌하므로 **보관소 대조 맥락에서만** 언급했다
- **§8(기준 문서 낡음)대로 보고했다.** 프로필이 스스로 건 트립와이어 3개 중 2개가 이미 울려 있다(결정 최신일 08-17≠08-18, 갱신일 이후 코드 변경 있음)
- **숫자는 세어서 적었다.** lib 38 / API 35 / 테이블 17 / adminMenu 9는 전부 `git ls-tree`·`grep` 실측
