## 대표님께 — 다섯 줄

1. 새 화면 코드가 **작업용 가지에만 있고 실제 서비스 쪽에는 없습니다.** 지금 스위치를 켜면 새 화면이 아니라 옛 화면이 나옵니다.
2. 이 코드를 **세 덩어리로 나눠** 내보내기를 제안합니다 — ① 옛·새 화면이 **같이 쓰는 부품** ② **새 화면 3장**(모임 상세·신청 확인·신청 완료) ③ **옛 화면 잔손질 4곳**.
3. 나누는 기준은 **문제가 생겼을 때 무엇까지 같이 되돌아가느냐**입니다. ②는 스위치를 내리면 1초 만에 사라지지만, ①③은 되돌리려면 코드를 물려야 합니다. 그래서 섞지 않습니다.
4. **켜는 날 당일이 아니라 지금부터 3주에 걸쳐 미리 내보냅니다.** 스위치가 꺼져 있는 동안은 회원에게 아무것도 안 보이므로 **미리 내보내도 손해가 없고**, 당일에 몰면 확인할 시간이 사라집니다.
5. 제일 큰 위험은 코드가 아니라 **순서**입니다 — 남은 할 일(로그아웃 자리, 신규 회원 첫 화면, 옛 화면으로 새는 곳)이 **전부 ②번 위에 얹히는 일**이라, ②를 늦게 내보내면 그 작업들이 **다시 하게 됩니다.**

## 4. 런북 §1 어디에 끼우나 — **끼우지 않는다. 당일 전에 끝낸다**

### 답: `#50 → #49 → #53`의 **앞도 뒤도 중간도 아니다.** 그 목록 **바깥**, 켜는 날 **이전**이다.

근거 넷:

**(1) 기존 제약을 건드리지 않는다.** `#50 → #49 → #53`이 제약인 이유는 **그 셋이 서로 얹혀 있는 스택 PR**이기 때문이다(DECISIONS 2026-08-22 · 런북 §1-3). 새 PR 3개는 **전부 `main`에서 갈라져 나오고 서로도 그 셋과도 스택 관계가 아니다.** 제약의 적용 대상이 아니다.

**(2) 🔴 런북 §1의 「재배포 금지 구간」에 들어가면 안 된다.** 런북 §1 표 **1행(env 교체) ~ 2행(머지) 사이**에는 어떤 배포도 일어나면 안 된다 — 그 사이 재배포가 뜨면 **「새 코드 + 구 템플릿 ID」로 도는 창**이 열린다(§1-2). PR 머지는 자동 배포를 일으킨다. **그래서 당일 목록에 끼우는 선택지 자체가 없다.** 전체목록 **C1**(PR #40을 켜는 날 전에 닫으라)과 같은 논리다.

**(3) 플래그가 OFF인 동안 조기 머지 비용이 0이다.** 관리자·대표님이 2026-09-19에 이미 이 논리로 판단했다 — *"`next_ui`가 OFF인 동안은 `(next)`를 아무리 고쳐도 회원 노출이 0이다. 지금 만들어도 위험이 없고, 켜는 날에는 완성된 상태로 켜진다."* 반대로 당일에 6개(기존 3 + 신규 3)를 몰면 **무엇이 원인인지 못 가른다.**

**(4) 날짜와 범위가 둘 다 고정이면 남는 여유는 검증 시간뿐이다**(관리자 2026-09-19). 조기 머지 = 검증 시간을 버는 유일한 수단.

## 5. 어떻게 꺼내나 (실행은 개발·운영)

### 5-1. cherry-pick이 아니라 **경로 단위 체크아웃**을 권고한다

`06b3e00` 한 커밋에 ①과 ②가 섞여 있어 **커밋 단위로는 덩어리를 못 나눈다.** 또 세 커밋 모두 부서 로그·조사 문서·시안 PNG가 함께 들어 있어 cherry-pick하면 문서까지 따라온다.

```bash
# ① 예시 (실행 전 승인 필요)
git switch -c feat/next-shared-detail origin/main
git checkout feat/agent-team -- <①의 16개 경로>
npm run prelaunch   # jidokhae-web/
```

- `feat/agent-team`의 **최종 상태**를 가져온다 → `c8a8b89`·`e926f22`의 후속 수정이 자동으로 반영된다 (실측 확인)
- ⚠️ 대신 **"왜 이렇게 고쳤는가"가 사라진다.** PR 본문에 원 커밋 `06b3e00`·`c8a8b89`·`e926f22`와 근거 문서 3종(`docs/agent-team/조사/2026-08-25-*`, `2026-08-26-버튼-도착지-전수.md`)을 링크할 것
- 🔴 **`feat/agent-team`을 되감거나 `main` 기준으로 리셋하지 않는다.** 2026-09-11에 비슷한 자리에서 웹훅 수정 전체를 날릴 뻔했다(관리자 로그)

### 5-2. ② 가 ① 에 의존한다 — 실측

`git show feat/agent-team:<파일> | grep '^import'` 로 확인:

| ②의 파일 | ①에서 가져오는 것 |
|---|---|
| `(next)/meet/[id]/page.tsx` · `apply/page.tsx` | `loadMeetingDetail` (`lib/meeting-detail.ts`) |

**반대 방향은 0건** — ①의 16파일 중 `components/next/*`나 `app/(next)/*`를 import하는 것은 없다(전수 grep). **① 단독으로 빌드된다.**

**권고** — #66은 이미 draft이고 켜는 날 뒤로 밀려 있다(DECISIONS 2026-08-22). 그 행에 **새 사실 한 줄을 더해야 한다**: *"#66이 손으로 풀어야 할 자리가 `profile/setup/route.ts` 하나에서 **`payment-redirect` 하나가 더 늘었고, 그쪽은 파일이 사라져 옮겨 붙여야 한다**"*. → 전체목록 **C2**에 반영 요청. **DECISIONS에 한 줄 추가했다**(§8).
