## 실제 값을 넣어보고 정한 것

### 모임 제목은 그대로 둔다

최근 모임 제목이 전부 `매주 수요일 정기모임`이다. 회차 구분이 안 되고 `8월 12일 (수)`와 나란히 두면 "수요일"이 두 번 나온다.

**그래도 바꾸지 않는다** (2026-08-11 결정) — 매주 반복 생성이라 회차마다 손으로 다는 건 운영 부담이 크다. `■ 모임:` 줄은 유지한다. 회차 구분은 못 해도 **정기모임인지 토론모임인지는** 구분해준다.

### 강조 타이틀이 용건을 맡는다

본문 첫 줄에 이름·날짜·모임명을 다 넣으면 잠금화면에서 용건이 잘린다. **강조 타이틀에 용건을 두고 본문 첫 줄은 지똑똑의 인사로** 쓴다.

## 1. 신청 완료 — `REGISTRATION_CONFIRM_V2`

```
[강조]  신청 확정!
[부제]  자리 하나 맡아뒀어요

똑똑! 우제님, 신청이 확정됐어요.

■ 모임: 매주 수요일 정기모임
■ 일시: 8월 12일 (수) 오후 7:00
■ 장소: 우연히 책방
■ 참가비: 12,000

전날 저녁에 한 번 더 알려드릴게요. 그때 봬요.

*취소는 마이페이지에서 할 수 있어요.
*환불 기준은 환불정책 페이지에서 확인하실 수 있어요.
```
버튼: `내 신청 확인` → `/my`

| 바꾼 것 | 왜 |
|---|---|
| `원` 제거 | 확정 규칙 |
| `전날 저녁에 한 번 더 알려드릴게요` | 이 메시지의 남은 불안은 "잊어버리면?"이다 |
| 취소 안내를 부가정보로 | 결제 직후 마지막 인상이 취소 경로면 안 된다 |

## 2. 모임 전날 — `MEETING_REMIND_V2`

```
[강조]  내일 만나요!
[부제]  책 한 권만 챙겨 오세요

똑똑! 우제님, 내일이 모임 날이에요.

■ 일시: 8월 12일 (수) 오후 7:00
■ 장소: 우연히 책방
■ 참가비: 12,000 (결제완료)

읽으실 책 한 권 들고 오시면 돼요. 기다릴게요.

*모임에 신청하신 분께 보내는 안내예요.
```
버튼: `모임 상세 확인` → `/meetings/#{모임ID}`

| 바꾼 것 | 왜 |
|---|---|
| **`(결제완료)` 고정 → `(#{결제상태})`** | **결함 1.** 미입금자에게도 "결제완료"라고 단언하고 있었다 |
| `참석해주세요` → `내일이 모임 날이에요` | 이미 돈 낸 사람에게 내리는 지시였다 |
| `읽으실 책 한 권 들고 오시면 돼요` | 전날 밤에 필요한 건 준비물이다 |

> ⚠️ 이 템플릿은 **코드 변경이 함께 나가야 한다.** `#{결제상태}` 값을 보내는 코드가 브랜치 `fix/remind-payment-status`에 있다.
> 부가정보(extra)에는 변수를 넣을 수 없어 발송 근거에서 `#{모임명}`을 뺐다.

## 3. 대기 신청 — `WAITLIST_CONFIRM_V2`

```
[강조]  대기 신청 접수!
[부제]  자리가 나면 바로 알려드려요

똑똑! 우제님, 대기 신청이 접수됐어요.

■ 모임: 매주 수요일 정기모임
■ 일시: 8월 12일 (수) 오후 7:00
■ 장소: 우연히 책방
■ 결제 금액: 12,000

자리가 나면 순서대로 알려드릴게요.
전날까지 자리가 나지 않으면 전액 환불해드려요.

*취소는 마이페이지에서 할 수 있어요.
```
버튼: `내 신청 확인` → `/my`

대기 회원이 가장 궁금한 두 가지(**언제 알려주나 / 안 되면 돈은**)가 원래 없었다. 넣은 두 줄은 실제 동작과 일치한다.

## 4. 자리 났음 — `WAITLIST_PROMOTED_V2`

```
[강조]  자리가 났어요!
[부제]  기다린 보람이 있네요

똑똑! 우제님, 좋은 소식이에요.

기다리시던 자리가 생겼어요.

■ 모임: 매주 수요일 정기모임
■ 일시: 8월 12일 (수) 오후 7:00
■ 장소: 우연히 책방
■ 결제 금액: 12,000 (결제완료)

전날 저녁에 다시 알려드릴게요. 그때 봬요.
```
버튼: `모임 상세 확인` → `/meetings/#{모임ID}`

`대기 중이던 모임의`를 뺐다 — 본인이 아는 사실이라 잡초다.

> ⚠️ `(#{결제상태})`로 바꿨다. **계좌이체로 대기 신청한 회원은 미입금 상태로 승격될 수 있다.** 여기도 코드에서 값을 넣어줘야 한다.

## 5. 미승격 환불 — `WAITLIST_REFUNDED_V2`

```
[강조]  이번엔 자리가 나지 않았어요
[부제]  결제 금액은 전액 돌려드려요

똑똑! 우제님, 아쉬운 소식이에요.

이번 모임은 끝까지 자리가 나지 않았어요.

■ 모임: 매주 수요일 정기모임
■ 일시: 8월 12일 (수) 오후 7:00
■ 환불 금액: 12,000 (전액)

따로 하실 일은 없어요. 다음 모임에서 만나요.

*카드 결제는 카드사 처리에 영업일 3~5일이 걸려요.
```
버튼: `다른 모임 보기` → `/`

| 바꾼 것 | 왜 |
|---|---|
| `승격` 제거 | 내부 용어다. 회원은 어디서 어디로 올라갔는지 모른다 |
| `매주 수요일 정기모임 모임의` | `모임`이 두 번이었다 |
| 환불 기한 단언 → 카드 조건 명시 | **계좌이체는 운영자가 직접 이체**해서 기한을 보장할 수 없다 |
| `따로 하실 일은 없어요` | 회원이 뭘 해야 하는지 원래 없었다 |
| `더 좋은 기회로` 제거 | 이번이 나빴다는 뉘앙스다 |

> **강조 타이틀에 느낌표를 쓰지 않은 유일한 템플릿이다.** 돈을 잃은 자리에서 발신자가 신나면 안 된다.

## 6. 가입 환영 — `NEW_MEMBER_WELCOME_V2`

```
[강조]  환영해요!
[부제]  각자 책 들고 모이는 곳이에요

똑똑! 우제님, 반가워요.

지독해는 각자 읽을 책을 들고 와서
함께 읽고 이야기하는 모임이에요.

다가오는 모임은 아래에서 볼 수 있어요.

▪ 지독해에 가입하신 분께 보내는 안내예요.
```
버튼: `모임 보기` → `/`

| 바꾼 것 | 왜 |
|---|---|
| **모임 정보 제거** | 기존 문안은 **가입 다음날 모임이 있다고 전제**했다. 가입 시점과 첫 모임 사이가 비면 틀린 말이 된다 |
| 이모지·느낌표 정리 | 카톡에서 이모지는 광고 신호다 |
| `책은 거들 뿐!` 제거 | 재치를 노린 문장인데 **책을 안 읽어도 된다는 뜻으로 읽힌다.** 우리 모임은 각자 책을 들고 온다 |
| 우리가 어떤 모임인지 한 문장 | 다른 독서모임과 다른 지점이라 첫인사에 값어치가 있다 |

## 7. 물어보기 — `BOOK_ASK` (신규)

```
[강조]  읽으신 책 담아보세요
[부제]  서재에 한 권씩 쌓여요

똑똑! 우제님, 8월 12일 (수) 모임 다녀오셨죠.

그날 읽으신 책을 서재에 담아두실 수 있어요.
아래 버튼을 누르면 바로 담겨요.

담아둔 책은 마이페이지에서 다시 볼 수 있어요.

▪ 모임당 한 번만 보내드려요.
```
버튼: `책 담기` → `/my`

| 정한 것 | 왜 |
|---|---|
| 착지를 `/my`로 | 모임 상세는 담기 스트립이 맨 아래라 스크롤해야 나온다 |
| 모임명 제외 | 매번 같아서 구분이 안 되고 `(수)`와 중복된다 |
| `모임당 한 번만` 명시 | 한 번만 보낸다는 사실이 "안 해도 된다"의 가장 강한 신호다 |
| 대가 없음 | 쿠폰·경품을 걸면 광고성이 되어 심사 반려다 |
