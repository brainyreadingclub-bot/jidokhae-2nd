## ⚠️ 먼저 — 실제 값을 넣어보니 드러난 것

### 모임 제목이 정보를 담고 있지 않다

최근 모임 제목이 **전부 `매주 수요일 정기모임`**이다. 회차 구분이 안 되고, `8월 12일 (수)`와 나란히 두면 **"수요일"이 두 번** 나온다.

```
■ 모임: 매주 수요일 정기모임
■ 일시: 8월 12일 (수) 오후 7:00     ← 수요일이 중복
```

**시안에서는 `■ 모임:` 줄을 유지했다.** 토론모임이 생기면 구분자가 필요하기 때문이다. 다만 지금 상태로는 잡초에 가깝다.

> **판단 필요** — 모임 제목을 `8월 12일 정기모임`처럼 회차가 드러나게 바꾸면, 이 중복이 사라지고 알림톡·화면 양쪽이 같이 좋아진다. 운영 쪽 변경이라 재윤 결정이 필요하다.

### 첫 줄에 모임명·날짜를 넣으면 용건이 잘린다

잠금화면은 약 20자에서 자른다. `똑똑!` 다음에 **용건**을 바로 두고, 이름·날짜는 아래로 내렸다.

## 1. 신청 완료 — `REGISTRATION_CONFIRM`

**현재**
```
우제님, 모임 신청이 확정되었습니다!

■ 모임: 매주 수요일 정기모임
■ 일시: 8월 12일 (수) 오후 7:00
■ 장소: 우연히 책방
■ 결제 금액: 12,000원
```

**시안**
```
똑똑! 신청이 확정됐어요.

■ 모임: 매주 수요일 정기모임
■ 일시: 8월 12일 (수) 오후 7:00
■ 장소: 우연히 책방
■ 참가비: 12,000

우제님, 전날 저녁에 한 번 더 알려드릴게요.

▪ 취소는 마이페이지에서 할 수 있어요.
```

| 바꾼 것 | 왜 |
|---|---|
| 느낌표 제거 | 지똑똑이 회원 대신 기뻐하지 않는다 |
| `원` 제거 | 확정 규칙 |
| `전날 저녁에 한 번 더 알려드릴게요` 추가 | 이 메시지의 남은 불안은 "잊어버리면?"이다 |
| 취소 안내를 맨 아래 `▪`로 | 결제 직후 마지막 인상이 취소 경로면 안 된다 |

첫 줄 **14자** — 미리보기에 다 들어간다.

## 2. 모임 전날 — `MEETING_REMIND`

**현재**
```
우제님, 내일 모임에 참석해주세요!

■ 모임: 매주 수요일 정기모임
■ 일시: 8월 12일 (수) 오후 7:00
■ 장소: 우연히 책방
■ 참가비: 12,000원 (결제완료)
```

**시안**
```
똑똑! 내일 모임에서 만나요.

■ 일시: 8월 12일 (수) 오후 7:00
■ 장소: 우연히 책방
■ 참가비: 12,000 (결제완료)

우제님, 읽으실 책 한 권 챙겨 오시면 돼요.

▪ 매주 수요일 정기모임에 신청하신 분께 보내는 안내예요.
```

| 바꾼 것 | 왜 |
|---|---|
| `참석해주세요` → `만나요` | 이미 돈 낸 사람에게 내리는 지시였다 |
| `(결제완료)` 고정 → `(#{결제상태})` | **결함 1.** 미입금자에게도 "결제완료"라고 단언하고 있었다 |
| `■ 모임:` 줄을 발송 근거 줄로 이동 | 같은 정보가 두 번 나오지 않게 |
| `읽으실 책 한 권 챙겨 오시면 돼요` | 전날 밤에 필요한 건 준비물이다 |

> `#{결제상태}` 값 — `결제완료` / `입금 확인 중`
> ⚠️ **`MEETING_REMIND_V2`가 이미 검수 중이다.** 그건 결함만 고친 합쇼체 버전이라, 이 시안은 승인 이후 별도 재작성으로 반영한다.

## 3. 대기 신청 — `WAITLIST_CONFIRM`

**현재**
```
우제님, 모임 대기 신청이 완료되었습니다.

■ 모임: 매주 수요일 정기모임
■ 일시: 8월 12일 (수) 오후 7:00
■ 장소: 우연히 책방
■ 결제 금액: 12,000원
```

**시안**
```
똑똑! 대기 신청이 접수됐어요.

■ 모임: 매주 수요일 정기모임
■ 일시: 8월 12일 (수) 오후 7:00
■ 장소: 우연히 책방
■ 결제 금액: 12,000

우제님, 자리가 나면 순서대로 알려드릴게요.
전날까지 자리가 나지 않으면 전액 환불해드려요.

▪ 취소는 마이페이지에서 할 수 있어요.
```

| 바꾼 것 | 왜 |
|---|---|
| 안내 두 줄 추가 | 대기 회원이 가장 궁금한 두 가지가 원래 없었다 — **언제 알려주나 / 안 되면 돈은** |

넣은 두 줄은 실제 동작과 일치한다(순번 자동 승격, 전날 크론 전액 환불). 지킬 수 있는 것만 적었다.

## 4. 자리 났음 — `WAITLIST_PROMOTED`

**현재**
```
우제님, 대기 중이던 모임의 자리가 나서 참여가 확정되었습니다!

■ 모임: 매주 수요일 정기모임
■ 일시: 8월 12일 (수) 오후 7:00
■ 장소: 우연히 책방
■ 결제 금액: 12,000원 (결제완료)
```

**시안**
```
똑똑! 자리가 났어요.

■ 모임: 매주 수요일 정기모임
■ 일시: 8월 12일 (수) 오후 7:00
■ 장소: 우연히 책방
■ 결제 금액: 12,000 (결제완료)

우제님, 참여가 확정됐어요.
전날 저녁에 한 번 더 알려드릴게요.
```

| 바꾼 것 | 왜 |
|---|---|
| 첫 줄을 **11자**로 | 서비스에서 가장 반가운 소식이 미리보기에서 잘리지 않는다 |
| `대기 중이던 모임의` 삭제 | 본인이 아는 사실이다. 잡초 |

> ⚠️ 여기 `(결제완료)`도 고정 문구다. **계좌이체로 대기 신청한 회원은 미입금 상태로 승격될 수 있다.** 재작성 때 `#{결제상태}`로 바꾼다.

## 5. 미승격 환불 — `WAITLIST_REFUNDED`

**현재**
```
우제님, 매주 수요일 정기모임 모임의 대기 중 승격되지 않아 결제 금액이 환불됩니다.

■ 환불 금액: 12,000원 (전액)
■ 환불 예정: 영업일 기준 3~5일

다음에 더 좋은 기회로 뵙겠습니다.
```

**시안**
```
똑똑! 이번엔 자리가 나지 않았어요.

■ 모임: 매주 수요일 정기모임
■ 일시: 8월 12일 (수) 오후 7:00
■ 환불 금액: 12,000 (전액)

우제님, 따로 하실 일은 없어요.

▪ 카드 결제는 카드사 처리에 영업일 3~5일이 걸려요.

다음 모임에서 만나요.
```

| 바꾼 것 | 왜 |
|---|---|
| `승격` 제거 | 내부 용어다. 회원은 어디서 어디로 올라갔는지 모른다 |
| `매주 수요일 정기모임 모임의` | `모임`이 두 번이었다. 잡초 |
| 환불 기한 단언 → 카드 조건 명시 | **계좌이체는 운영자가 직접 이체**해서 기한을 보장할 수 없다 |
| `따로 하실 일은 없어요` 추가 | 회원이 뭘 해야 하는지 원래 없었다 |
| `더 좋은 기회로` 제거 | 이번이 나빴다는 뉘앙스다 |
| `이번엔` 추가 | 일회성 사건이라는 신호. 다음이 있다 |

## 6. 물어보기 — `BOOK_ASK` ✅ 반영 완료

```
똑똑! 읽으신 책을 서재에 담아보세요.

우제님, 8월 12일 (수) 모임에 참여하신 분께 보내는 안내예요.
아래 버튼을 누르면 서재에 담을 수 있어요.

담아둔 책은 마이페이지에서 다시 볼 수 있어요.

▪ 모임당 한 번만 보내드려요.
```

버튼: `책 담기` → `https://brainy-club.com/my`

첫 줄 **20자.** 모임명을 뺀 이유는 위 ⚠️ 참조 — 매번 같아서 구분이 안 되고 `(수)`와 중복된다.

## 7. 가입 환영 — `NEW_MEMBER_WELCOME`

**현재** (코드 미연결)
```
지독해 멤버가 되신 걸 축하드려요.

내일 매주 수요일 정기모임에서 첫 인사를 나누겠네요.

📍 우연히 책방 오후 7:00
📚 준비물: 가벼운 마음 (책은 거들 뿐!)

내일 즐겁게 이야기 나눠요!
```

**시안**
```
똑똑! 지독해에 오신 걸 환영해요.

우제님, 지독해는 각자 읽을 책을 들고 와서
함께 읽고 이야기하는 모임이에요.

다가오는 모임은 아래에서 볼 수 있어요.

▪ 지독해에 가입하신 분께 보내는 안내예요.
```

| 바꾼 것 | 왜 |
|---|---|
| 이모지 제거 | 카톡에서 이모지는 광고 신호다 |
| 느낌표 제거 | |
| **모임 정보 제거** | 현재 문안은 **가입 다음날 모임이 있다고 전제**한다. 가입 시점과 첫 모임 사이가 비면 틀린 말이 된다 |
| 우리가 어떤 모임인지 한 문장 | 각자 책을 들고 온다는 게 다른 독서모임과 다른 지점이다 |
| `책은 거들 뿐` 제거 | 재치를 노린 문장인데 **책을 안 읽어도 된다는 뜻으로 읽힐 수 있다.** 우리 모임은 각자 책을 들고 온다 |

## 진행 순서

| # | | 상태 |
|:--:|---|---|
| 1 | `BOOK_ASK` | ✅ 반영 완료 · 검수 요청 대기 |
| 2 | `MEETING_REMIND_V2` · `WAITLIST_REFUNDED_V2` | 검수 중 (결함 수정분, 합쇼체) |
| 3 | 위 2번 승인 후 → 전체를 지똑똑 목소리로 재작성 | 대기 |

> 2번을 지금 취소하고 3번으로 합치면 **결함 수정이 또 밀린다.** 승인부터 받고 정리한다.
