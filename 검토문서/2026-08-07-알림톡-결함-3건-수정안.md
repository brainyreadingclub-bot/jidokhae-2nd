# 알림톡 결함 3건 수정안

> 2026-08-07 | 작성: 총괄 | **배포 금지 — 문구 확정만**
> 원문은 Solapi API(`getKakaoAlimtalkTemplates`)로 조회한 실제 승인 템플릿이다.

## 이 문서의 성격

라이팅 가이드보다 **먼저** 처리한다. 세 건 중 하나는 **회원이 지금 잘못된 정보를 받고 있는 문제**다.

**어미는 손대지 않는다.** 현행 템플릿이 합쇼체이므로 수정안도 합쇼체를 유지한다. 어미 결정(가이드 §6)이 난 뒤에 문안 전면 재작성을 별도로 한다. 지금은 **결함만** 고친다.

---

## 결함 1 — 🔴 리마인드가 미입금자에게 "결제완료"라고 단언한다

**대상**: `MEETING_REMIND` (`SOLAPI_TEMPLATE_REMIND`)

### 현재

```
#{회원명}님, 내일 모임에 참석해주세요!

■ 모임: #{모임명}
■ 일시: #{모임일시}
■ 장소: #{장소}
■ 참가비: #{참가비}원 (결제완료)
```

### 무엇이 문제인가

마지막 줄의 `(결제완료)`가 **변수가 아니라 고정 문구**다.

PR #44로 리마인드 대상에 `pending_transfer`(입금 확인 전)를 포함시킨 뒤부터, **아직 입금하지 않은 회원도 "결제완료"라고 쓰인 메시지를 받고 있다.**

- 입금을 잊은 회원 → "냈다고 하네" 하고 넘어간다
- 이미 낸 회원 → 문제없지만, 두 경우를 문면으로 구분할 수 없다

### 수정

```
#{회원명}님, 내일 모임에 참석해주세요!

■ 모임: #{모임명}
■ 일시: #{모임일시}
■ 장소: #{장소}
■ 참가비: #{참가비}원 (#{결제상태})
```

| 주입값 | 조건 |
|---|---|
| `결제완료` | `confirmed` |
| `입금 확인 중` | `pending_transfer` |

### 필요한 작업

| # | |
|---|---|
| 1 | 템플릿에 `#{결제상태}` 변수 추가 → **카카오 재심사** |
| 2 | `notification.ts`의 리마인드 래퍼에 `'#{결제상태}'` 전달 추가 |
| 3 | **템플릿 승인과 코드 배포를 같이 내보낸다.** 템플릿이 먼저 교체되면 코드가 변수를 안 보내 발송이 실패한다 |

> `참석해주세요!`(강요·느낌표)는 이 결함과 별개다. 어차피 재심사에 올라가므로 **문안 전면 재작성 때 함께** 처리하는 편이 재심사 횟수를 줄인다. 다만 어미가 미정이라 지금 확정하지 않는다.

## 결함 2 — `승격`이라는 내부 용어가 회원에게 나간다

**대상**: `WAITLIST_REFUNDED` (`SOLAPI_TEMPLATE_WAITLIST_REFUNDED`)

### 현재

```
#{회원명}님, #{모임명} 모임의 대기 중 승격되지 않아 결제 금액이 환불됩니다.

■ 환불 금액: #{결제금액}원 (전액)
■ 환불 예정: 영업일 기준 3~5일

다음에 더 좋은 기회로 뵙겠습니다.
```

### 무엇이 문제인가

- **`승격`은 개발 용어다.** 회원은 자기가 어디서 어디로 올라갔는지 모른다 (가이드 §3-7 위반)
- **잡초** — `#{모임명} 모임의`에서 `모임의`가 중복이다 (§3-1 위반)
- **`영업일 기준 3~5일`을 무조건 단언한다.** 카드는 카드사가 처리하니 맞지만, **계좌이체는 운영자가 직접 이체**하므로 그 기한을 보장할 수 없다
- **`다음에 더 좋은 기회로`** — 이번이 나빴다는 뉘앙스다

### 수정

```
#{회원명}님, #{모임명} 자리가 나지 않아 결제 금액을 환불해 드립니다.

■ 환불 금액: #{결제금액}원 (전액)

▪ 카드 결제는 카드사 처리에 영업일 3~5일이 걸립니다.

다음 모임에서 뵙겠습니다.
```

### 필요한 작업
카카오 재심사만. 코드 변경 없음(변수 동일).

## 결함 3 — 좋은 소식이 잠금화면에서 잘린다

**대상**: `WAITLIST_PROMOTED` (`SOLAPI_TEMPLATE_WAITLIST_PROMOTED`)

### 현재

```
#{회원명}님, 대기 중이던 모임의 자리가 나서 참여가 확정되었습니다!
```

### 무엇이 문제인가

잠금화면 미리보기는 앞부분만 보인다. 지금 구조로는 이렇게 잘린다.

```
초록고래님, 대기 중이던 모임의 자…
```

**서비스에서 가장 반가운 소식인데, 열어보기 전에는 그게 좋은 일인지 알 수 없다.** 앞의 `대기 중이던 모임의`는 회원이 이미 아는 정보라 잡초이기도 하다(§3-1, §3-3).

### 수정

```
#{회원명}님, 자리가 났습니다.

■ 모임: #{모임명}
■ 일시: #{모임일시}
■ 장소: #{장소}
■ 결제 금액: #{결제금액}원 (결제완료)

참여가 확정되었습니다.
```

잘리는 구간에서 이렇게 보인다.

```
초록고래님, 자리가 났습니다.
```

> ⚠️ 이 템플릿의 `(결제완료)`도 고정 문구다. **계좌이체로 대기 신청한 회원은 미입금 상태로 승격될 수 있으므로** 결함 1과 같은 문제를 안고 있다. 재심사에 올릴 때 `#{결제상태}`로 함께 바꾸는 것을 권한다.

### 필요한 작업
카카오 재심사. `#{결제상태}`까지 함께 바꾸면 코드 변경 1건 추가.
