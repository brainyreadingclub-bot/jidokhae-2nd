## 1. 실행 전 막아야 할 것 2건

### 🔴 A. 승인된 템플릿을 수정 접수하면 발송이 멈춘다

알림톡 템플릿은 `추가 → 검수 요청 → 검수 중 → 검수 완료 → 발송 가능` 단계를 거친다. **승인된 템플릿을 수정하면 다시 검수 상태가 되고, 검수 중에는 발송할 수 없다.**

`MEETING_REMIND`는 **매일 KST 19:00 크론이 도는 살아 있는 템플릿**이다. 이걸 수정 접수하면 심사가 끝날 때까지(수일) **전 회원이 모임 전날 안내를 못 받는다.**

| | 지금 결함 | 수정 접수 시 |
|---|---|---|
| 영향 | 미입금자가 `결제완료`로 오해 | **전 회원이 리마인드를 못 받음** |
| 범위 | 계좌이체 미입금자 | 신청자 전원 |

**고치려다 더 큰 문제를 만든다.**

**대안 — 신규 템플릿 등록 방식**

```
① MEETING_REMIND_V2 를 새로 등록 + 심사 접수   (기존 템플릿은 그대로 발송)
② 승인되면 SOLAPI_TEMPLATE_REMIND 값을 V2로 교체 + 코드 배포
③ 안정 확인 후 구버전 삭제
```

무중단이고, 승인이 늦어져도 손해가 없다. 결함 2·3도 같은 방식으로 처리한다.

### 🔴 B. 코드를 `main`에 커밋하면 그 순간 배포된다

Vercel이 `main` push에 프로덕션 배포를 건다. 지시대로 **"승인 후 배포"를 지키려면 코드를 `main`에 넣으면 안 된다.**

**대안** — 코드는 브랜치(`fix/remind-payment-status`)에만 두고 **PR을 미머지 상태로** 유지한다. 템플릿 승인 시점에 머지한다.

## 3. POST_MEETING — 판단 근거

### 템플릿 원문

```
#{이름}님, 유쾌한 자극이 되었기를 바랍니다.

오늘의 감상이 휘발되기 전에
짧은 기록으로 남겨주세요.

나중에 꺼내 보면 좋은 추억이 됩니다.☺
```
버튼: `기록 남기기` → `https://brainy-club.com/my/reviews`

### 조사한 것

| 항목 | 결과 |
|---|---|
| **리뷰·후기 기능 계획** | **없다.** `roadmap/milestones-phase3.md`(M7~M12), `work-packages-phase3.md`, `phase3-requirements.md`, `core/*` 전수 검색 결과 후기·리뷰 기능이 어디에도 없다 |
| **`/my/reviews` 라우트** | **없다.** `src/app/(main)/my/`에 `page.tsx` 하나뿐이다 |
| **MVP 제외 목록** | 배지·콩·랜딩·관리자 분석·AI 챗봇·book tracking이 제외로 명시돼 있으나 **후기는 아예 언급조차 없다** |

### 이 자리는 이미 다른 게 차지했다

`POST_MEETING`이 노리는 자리(**모임 다녀온 직후, 기록을 남기게 하는 것**)는 현재 **서재 + 물어보기**가 맡고 있다. 6번째 알림톡(물어보기)도 같은 타이밍(모임 다음날)에 발송 예정이다.

| | POST_MEETING | 물어보기 (6번째, 준비 중) |
|---|---|---|
| 시점 | 모임 후 | 모임 다음날 |
| 요구 | **감상을 글로 쓰기** | **읽은 책 담기** |
| 마찰 | 높다 | 낮다 (검색 후 탭) |
| 착지 | 없는 라우트 | `/my` |

**두 개를 다 살리면 같은 타이밍에 알림톡이 두 통 나간다.** 층 B 총량 문제로 이어진다.

### 판단이 갈리는 지점

| | 살릴 때 | 접을 때 |
|---|---|---|
| 필요한 것 | `/my/reviews` 라우트 + 후기 작성·저장·조회 기능 + 템플릿 재심사(문구·링크) | 삭제 또는 보류 처리만 |
| 얻는 것 | 감상 기록이라는 다른 축 | 알림 총량 유지, 물어보기에 집중 |
| 비용 | 신규 기능 하나. 물어보기와 자리 경쟁 | 없음 |

> **총괄 의견** — 접는 쪽을 권한다. 리뷰 기능이 로드맵에 없고, 그 자리를 물어보기가 이미 맡았으며, 물어보기의 응답률조차 아직 측정하지 못한 상태다(플래그 OFF). 다만 **삭제가 아니라 보류**로 두면 나중에 후기 기능이 생길 때 문안을 재사용할 수 있다.
>
> **결정은 재윤 몫이다.**
